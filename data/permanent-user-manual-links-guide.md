# Permanent User Manual Links Guide

> 2026-09-01

## Overview

Each product's user manual has a **permanent, stable URL** for QR codes, printed materials, etc. No matter how the manual content is updated, version numbers change, or files are renamed, this link always points to the latest version.

## QR Code URL Pattern

```
English: https://www.inhand.com/manuals/{Product}/user-manual.html
Chinese: https://www.inhand.com.cn/manuals/{Product}/user-manual.html
```

`{Product}` is the product directory name under `docs/{lang}/` in the documents repository.

### Examples

| Product Directory | English Link | Chinese Link |
|---------|---------|---------|
| EC300 | `https://www.inhand.com/manuals/EC300/user-manual.html` | `https://www.inhand.com.cn/manuals/EC300/user-manual.html` |
| VG814 | `https://www.inhand.com/manuals/VG814/user-manual.html` | `https://www.inhand.com.cn/manuals/VG814/user-manual.html` |
| LoRaWAN Terminals | `https://www.inhand.com/manuals/LoRaWAN%20Terminals/user-manual.html` | `https://www.inhand.com.cn/manuals/LoRaWAN%20Terminals/user-manual.html` |

> Spaces in directory names are URL-encoded as `%20`.

## For Maintainers

### No Extra Work Needed

Redirect pages are **auto-generated by CI/CD**. Every push to master triggers a deployment, which automatically generates redirect pages for all products that have user manuals.

### Common Scenarios

| Scenario | What to Do | Impact on Permanent Link |
|------|-----------|----------------|
| Manual content updated (same filename) | Commit and push as usual | ❌ No impact |
| Version upgrade (new filename V2.0) | Commit and push as usual | ❌ No impact |
| File renamed | Commit and push as usual | ❌ No impact |
| User manual deleted | Commit and push as usual | ⚠️ Redirect returns 404 |
| New product user manual added | Place in `Manuals/User manual/` or `Manuals/用户手册/` | ✅ Redirect auto-generated |

### Directory Structure Requirement

The script only looks at directory locations, never parses filenames. Just place the user manual md file in the correct directory:

```
docs/en/{Product}/Manuals/User manual/any-filename.md     ← English
docs/zh/{Product}/Manuals/用户手册/任意文件名.md            ← Chinese
```

Filename doesn't matter — with or without version numbers, Chinese or English.

### Important Notes

1. **Only one user manual file per product directory**. If multiple .md files exist, the script picks the first one and logs a warning
2. **Don't place non-manual files in `User manual/` or `用户手册/` directories**
3. Products without a user manual won't get a redirect page (404), this is expected

## Technical Details

### Script

`scripts/generate_manual_redirects.py`

Runs in `deploy-manuals.yml` after mkdocs build, before rsync deployment:

```yaml
- name: Generate manual redirects
  run: |
    python scripts/generate_manual_redirects.py --site-dir site-zh --lang zh
    python scripts/generate_manual_redirects.py --site-dir site-en --lang en
```

### How It Works

1. Scans `site/{Product}/Manuals/User manual/` (en) or `site/{Product}/Manuals/用户手册/` (zh) directories
2. Finds `.html` files (excludes MkDocs auto-generated `index.html`)
3. Generates a `<meta http-equiv="refresh">` redirect page at `site/{Product}/user-manual.html`
4. Deployed to the server along with the site via rsync

### Trigger

Same as site deployment — automatically triggered when `docs/**` changes. Modifying the script itself does NOT trigger a deployment; manually trigger from the Actions page if needed.
