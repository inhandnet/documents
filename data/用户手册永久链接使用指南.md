# 用户手册永久链接使用指南

> 2026-09-01

## 这是什么

每个产品的用户手册有一个**永久固定链接**，用于生成二维码、印刷在说明书上等。不管手册内容怎么更新、版本号怎么变、文件名怎么改，这个链接始终指向最新版本。

## 二维码链接规则

```
英文：https://www.inhand.com/manuals/{产品名}/user-manual.html
中文：https://www.inhand.com.cn/manuals/{产品名}/user-manual.html
```

`{产品名}` 就是 documents 仓库里 `docs/{lang}/` 下的产品目录名，原样填入即可。

### 示例

| 产品目录 | 英文链接 | 中文链接 |
|---------|---------|---------|
| EC300 | `https://www.inhand.com/manuals/EC300/user-manual.html` | `https://www.inhand.com.cn/manuals/EC300/user-manual.html` |
| VG814 | `https://www.inhand.com/manuals/VG814/user-manual.html` | `https://www.inhand.com.cn/manuals/VG814/user-manual.html` |
| LoRaWAN Terminals | `https://www.inhand.com/manuals/LoRaWAN%20Terminals/user-manual.html` | `https://www.inhand.com.cn/manuals/LoRaWAN%20Terminals/user-manual.html` |

> 目录名含空格时 URL 中用 `%20` 替代。

## 维护人员需要知道的事

### 你不需要做任何额外操作

跳转页是 **CI/CD 自动生成**的。每次 push 到 master 触发部署时，脚本自动为所有有用户手册的产品生成跳转页。

### 手册更新的场景

| 场景 | 需要做什么 | 永久链接受影响吗 |
|------|-----------|----------------|
| 手册内容更新（同名覆盖） | 正常提交推送 | ❌ 不受影响 |
| 版本升级（新文件名 V2.0） | 正常提交推送 | ❌ 不受影响 |
| 文件改名 | 正常提交推送 | ❌ 不受影响 |
| 删除用户手册 | 正常提交推送 | ⚠️ 该产品跳转页失效（404） |
| 新增产品的用户手册 | 按目录规范放入 `Manuals/User manual/` 或 `Manuals/用户手册/` | ✅ 自动生成跳转页 |

### 目录结构要求

脚本只认目录位置，不解析文件名。把用户手册 md 放在正确的目录下即可：

```
docs/en/{产品名}/Manuals/User manual/你的文件名.md     ← 英文
docs/zh/{产品名}/Manuals/用户手册/你的文件名.md        ← 中文
```

文件名随意，带不带版本号、中文英文都行。

### 注意事项

1. **一个产品目录只放一个用户手册文件**。如果目录里有多个 .md 文件，脚本会取第一个并输出警告
2. **不要把非手册文件放在 `User manual/` 或 `用户手册/` 目录下**
3. 产品没有用户手册时不会生成跳转页，访问会 404，这是正常的

## 技术实现

### 脚本

`scripts/generate_manual_redirects.py`

在 `deploy-manuals.yml` 的 mkdocs build 之后、rsync 部署之前运行：

```yaml
- name: Generate manual redirects
  run: |
    python scripts/generate_manual_redirects.py --site-dir site-zh --lang zh
    python scripts/generate_manual_redirects.py --site-dir site-en --lang en
```

### 工作原理

1. 扫描 `site/{产品}/Manuals/User manual/`（en）或 `site/{产品}/Manuals/用户手册/`（zh）目录
2. 找到 `.html` 文件（排除 `index.html`）
3. 在 `site/{产品}/user-manual.html` 生成一个 `<meta http-equiv="refresh">` 跳转页
4. 部署时和站点一起 rsync 到服务器

### 触发条件

和站点部署一致，`docs/**` 变更时自动触发。修改脚本本身不会触发部署，需要手动到 Actions 页面触发。
