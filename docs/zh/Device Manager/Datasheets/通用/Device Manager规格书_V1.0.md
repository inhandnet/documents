# <span style="color: green;">1. 云平台概述</span>

**云端部署，海量接入，一站式设备管理**

Device Manager（以下简称 DM 平台）是由映翰通自主研发、自主运营的物联网设备管理云平台。通过可视化用户界面与标准化流程，可集中管理与监控映翰通路由器、网关等硬件，支持设备快速上云与海量设备批量管理。采用云端部署，无需本地服务器，用户可通过任意浏览器随时随地访问并管理全部已接入设备。

**产品特点：**

- **场景丰富：** 具备完善的设备管理能力，适用于各类行业应用场景
- **全球运维：** 足不出户管理分散在全球各地的映翰通硬件设备
- **协作与权限：** 多角色数据权限控制，IT 与 OT 团队可随时随地高效协作
- **协议接入：** 技术架构支持物联网广泛应用的 MQTT 协议
- **海量与弱网：** 适合低带宽、高延时现场环境，支持海量设备上云管理
- **开放集成：** 提供 RESTful API，便于二次开发并快速对接其他系统
- **安全合规：** CA 认证、数据加密、身份认证与访问控制，平台与设备协同保障安全

# <span style="color: green;">2. 运维挑战：分散设备难管</span>

传统物联网设备运维常见痛点：

| 集成商 / 运维团队 | 企业客户 |
| ----------------------- | -------------------- |
| 设备跨地域分布 — 上门成本高、响应慢 | 成百上千台设备各自 Web，缺少全局视图 |
| 批量配置与固件升级需逐台操作 | 从发现故障到定位根因周期长 |
| 多客户、多项目 — 权限隔离与协作复杂 | 告警分散 — 业务影响难以及时感知 |
| 边缘应用部署依赖现场 — 交付难规模化 | 设备数据难对接现有系统 — 信息孤岛 |

# <span style="color: green;">3. 核心管理能力</span>

## <span style="color: green;">运维总览</span>

登录后，首页 Dashboard 集中呈现在线/离线统计、流量使用与近期告警，无需逐台登录即可掌握全局。

- 在线 / 离线数量一目了然
- 流量趋势与告警摘要集中呈现
- 近期运维变更随时间可追溯

## <span style="color: green;">设备信息与远程 Web</span>

网关详情页统一展示机型、序列号、IP 地址、信号强度、IMSI、流量统计、在线历史与任务列表。设备周期性向平台上报运行数据，支撑实时监控与分析。

在线设备可直接从云端打开设备 Web 界面，修改配置并执行指令 — 无需现场接线或 VPN。

- 基本信息与运行信息一屏掌握
- 在线设备一键远程 Web 访问
- 任务状态实时反馈


## <span style="color: green;">远程配置与单设备固件升级</span>

针对在线设备，可在网关详情页编辑配置并远程下发。固件升级在上传后自动创建任务 — 在线设备立即执行，离线设备上线后补升。进度可在详情页实时跟踪。

若配置或升级反复失败，可使用强制离线使网关重新接入平台，提高下发成功率。

- 远程配置编辑与一键下发
- 单设备固件升级，支持离线补升
- 强制离线辅助故障恢复

**典型场景：** 偏远站点 IR600 需调整蜂窝拨号参数 — 运维人员通过 DM 更新并下发配置，无需上门。

## <span style="color: green;">告警监控</span>

平台监控网关关键事件，并通过短信或邮件通知指定用户。支持自定义告警规则与集中告警记录，便于追溯与处理。

- 设备上线/离线、流量超限、双 SIM 切换、链路备份、端口状态等
- 灵活规则，支持邮件与短信通知
- 告警列表集中呈现与处理

| DM 平台告警 | 说明 |
| ----------------- | ----------- |
| 网关上线/离线 | 设备接入或断开平台时触发 |
| 小时 / 日 / 月流量 | 流量超过设定阈值时触发 |images
| 双 SIM 切换 / 链路备份 | 当前活跃链路变更时触发 |
| 端口状态 | 拨号、LAN、WAN 端口 Up/Down 事件 |
| 电源切换 / 电池故障 | 电源相关状态变更（视机型） |


## <span style="color: green;">设备分组</span>

设备数量增长后，可按区域、行业或业务场景创建分组，便于有序管理。多级分组支撑大规模分层运维。

- 按业务维度灵活分组
- 支持设备移入、移出分组
- 多级分组适配复杂组织



## <span style="color: green;">位置跟踪（GIS）</span>

地图页实时展示网关位置与在线状态。点击设备图标可查看基本信息，点击名称可进入设备详情 — 适用于移动或地理分散部署。

- 地图查看位置与在线状态
- 从图标快速进入详情
- 适合车联网、移动巡检等场景


## <span style="color: green;">运行监控与统计分析</span>

分析视图展示在线统计与流量使用，并支持导出在线与流量列表。单设备在线柱状图有助于识别频繁掉线设备。

- 多维度在线与流量分析
- 单设备在线历史可视化
- 数据导出，便于报表与审计


## <span style="color: green;">任务跟踪</span>

任务列表展示经 DM 下发至设备的全部任务 — 配置、固件等。可对运行中任务重试或取消，实现可控、可追溯的批量操作。

- 配置、固件等任务统一跟踪
- 任务状态实时更新
- 支持重试与取消



## <span style="color: green;">批量配置与固件升级</span>

规模化场景下，使用配置管理与固件升级：上传模板或固件包，选择目标设备，批量下发，并监控整体与单台进度。

- 按机型匹配配置模板，批量下发至多台设备
- 批量固件升级，进度与状态可见
- 离线设备上线后自动执行

**典型场景：** 全国 200 台 IR600 需统一固件版本 — 上传固件包、选择全部设备、发起一次任务，并在任务列表跟踪每台状态。



## <span style="color: green;">边缘计算</span>

边缘计算模块面向 IG500、IG900、VG710 等网关 — 远程安装边缘引擎（SDK）与边缘应用（APP），并支持应用配置远程更新。

- 批量安装边缘 SDK，进度状态清晰
- 边缘应用版本管理与批量部署
- 远程下发应用配置，保留更新历史

> 请先安装边缘引擎，再安装边缘应用。



## <span style="color: green;">用户与权限管理</span>

支持多用户协作，通过网关权限组在既定范围内绑定用户与设备，实现数据隔离。组织管理员可管理全部设备与用户。

- 多用户账号与角色分配
- 自定义权限组，灵活绑定用户与设备
- 外部用户邀请与多组织切换

## <span style="color: green;">集成服务（MQTT / Kafka）</span>

通过配置外部 MQTT 或 Kafka 服务器，可将设备上报的流量、位置等数据推送至第三方系统；选择事件类型与自定义 Topic，快速完成业务对接。

- 对接 MQTT、Kafka 等外部服务
- 订阅上线/离线、时序、位置、设备信息等事件
- 配置完成后实时向第三方平台推送

# <span style="color: green;">4. 平台价值与效率提升</span>

| 任务 | 传统方式 | Device Manager 方式 |
| ---- | -------------------- | ------------------- |
| 月度设备巡检 | 逐台登录设备 Web — 耗时 | Dashboard + 统计分析 — 数分钟掌握全局 |
| 离线设备排查 | 逐页翻看、人工判断 | 在线历史、信号、告警集中呈现 — 更快定位根因 |
| 批量配置 | 逐台手工操作 | 上传模板、选择设备、一键批量下发 |
| 批量固件升级 | 逐台升级、人工跟进度 | 一次发起，任务列表跟踪每台设备 |
| 多区域权限控制 | 难隔离 — 存在数据泄露风险 | 权限组灵活绑定用户与设备 |
| 第三方数据对接 | 需自建采集器 | 集成服务 — MQTT/Kafka 开箱即用 |

**降低人力成本：** 运维无需逐台登录；批量操作与集中监控缩短日常维护时间；新人可快速上手。

**减少上门次数：** 远程 Web、配置与固件升级，多数工作可在云端完成 — 仅在确有必要时上门。

**支撑规模化运维（MSP / 集成商）：** 权限隔离与批量管理，使同一团队可高效服务多客户项目。


# <span style="color: green;">5. 安全与合规</span>

DM 从账号、权限、传输与审计等环节保护设备与数据。

| 安全机制 | 说明 |
| ------------------ | ----------- |
| CA 认证与加密 | 平台与设备间通信加密 |
| 身份认证与访问控制 | 多角色模型；组织管理员与普通用户区分 |
| 权限组隔离 | 用户仅可查看与管理授权组内设备 |
| 操作审计 | 系统日志记录登录、设备操作、固件升级等 |
| 账号规范 | 强密码、定期更换、离开时注销；通过用户管理授权 — 勿共用账号 |
