# EC3000 快速安装手册

---

## 第一部分：快速装机（图文整体流程）

> **您需要先做：** 开箱 → 固定设备 → 接电源与网线 →（若用蜂窝）**断电**装 SIM、接天线 → 上电 → PC 同网段 → HDMI 或 SSH 登录系统。  
> **再做：** 翻到下方 **第二部分**，按需查阅装箱、灯义、壁挂、各接口引脚等。

---

### 必读摘要（接线、上电前）

| 项目 | 要求 |
|------|------|
| 供电 | **9～36 V DC**，直流输入接口；**PWR 红灯常亮**表示已上电。 |
| SIM 卡 | **须断电**安装或拔出；**不可热插拔**。 |
| 天线 | 按壳体**丝印**拧紧；标配数量因型号而异（见《规格书》订购信息）。 |
| USB 存储 | 断开前执行 **sync** 命令，从 `/media/*` 目录退出后再拔。 |
| 接地 | 使用绿黄双色接地线（**16 AWG**）搭配接地螺丝接地。 |

---

### 步骤 1：对照实物，确认面板与接口区域

打开包装后，请先对照设备实物确认各面板布局。

前面板有 **PWR / STATUS / USER / 4G-5G** 指示灯、**2 个网口**、**4 个串口**、**CAN 口**、**数字量输入/输出**、**USB**、**HDMI** 等接口；侧面板有 **天线接口**、**SIM 卡槽**、**直流电源输入**、**接地螺丝**、**RESET 针孔**、**ON/OFF 开关**等。

![1748507699769-785eb2d0-1feb-44c0-bd75-562c508da61d.jpeg](./img/bXu8tvlaMDuH9WMP/1748507699769-785eb2d0-1feb-44c0-bd75-562c508da61d-074966.webp)

![1748507707558-d9198bdf-19d1-4aaa-bd43-b86012f8bc75.jpeg](./img/bXu8tvlaMDuH9WMP/1748507707558-d9198bdf-19d1-4aaa-bd43-b86012f8bc75-106615.webp)

> 各接口详细引脚定义见 §2.5；指示灯含义见 §2.3。

---

### 步骤 2：将设备固定到导轨或柜内

将 EC3000 的 DIN 导轨安装板上方挂钩卡入导轨顶端，再缓慢向前推，使底端卡入到位即可。

![1726621639249-b3ac993d-897c-4a80-8cd1-e2ad2f524001.jpeg](./img/bXu8tvlaMDuH9WMP/1726621639249-b3ac993d-897c-4a80-8cd1-e2ad2f524001-139958.webp)

> 如需壁挂安装，详见 §2.4.3；拆卸方式见 §2.4.2。

---

### 步骤 3：连接电源与以太网

将 DC 电源线接入侧面板的直流输入接口，再将网线接入 **ETH1** 或 **ETH2** 网口。

![1748510018454-9f0a14fc-4a3f-4348-a8a3-548619a3b76f.jpeg](./img/bXu8tvlaMDuH9WMP/1748510018454-9f0a14fc-4a3f-4348-a8a3-548619a3b76f-153758.webp)

![1748507720864-2a1b0709-f19c-4bba-8002-99417c573404.jpeg](./img/bXu8tvlaMDuH9WMP/1748507720864-2a1b0709-f19c-4bba-8002-99417c573404-538810.webp)

> 供电参数详见 §2.6；网口 LED 行为详见 §2.5.1；串口引脚详见 §2.5.2。

---

### 步骤 4：（若使用蜂窝）断电装 SIM，并接好天线

**务必在断电状态下操作。** 用配件盒中的取卡针按压 SIM 卡槽旁小孔，取出托盘，放入 Nano SIM 卡后推回插槽。按壳体丝印将蜂窝天线、Wi-Fi 天线、GNSS 天线拧紧到对应接口。

![1748510199214-968c752a-5f46-47ac-9118-80f571458b34.jpeg](./img/bXu8tvlaMDuH9WMP/1748510199214-968c752a-5f46-47ac-9118-80f571458b34-740868.webp)

![1748569482979-24f59256-7085-4078-acc2-e6255ffdd8a8.jpeg](./img/bXu8tvlaMDuH9WMP/1748569482979-24f59256-7085-4078-acc2-e6255ffdd8a8-760763.webp)

> 天线丝印与名称对照表见 §2.5.6；SIM 卡安装详情见 §2.5.6。

---

### 步骤 5：上电，确认设备已就绪

接通电源后，观察前面板指示灯：

- **PWR 红灯常亮** → 系统已开机
- **STATUS 绿灯约 1 Hz 慢闪** → 系统运行正常
- **4G/5G 绿灯常亮** → 蜂窝网络已连接（若使用蜂窝）

![1748508489416-b15b5a18-a3c6-4d33-9cf3-02b1523affe6.jpeg](./img/bXu8tvlaMDuH9WMP/1748508489416-b15b5a18-a3c6-4d33-9cf3-02b1523affe6-322761.webp)

> 各指示灯完整含义与闪烁频率定义见 §2.3。

---

### 步骤 6：PC 登录系统（HDMI 或 SSH）

**方式一：HDMI 直连**

通过 **HDMI1** 或 **HDMI2** 接口将设备与显示器连接，将键盘及鼠标接入设备的 USB 3.0 Host 接口。给设备上电后等待启动完成。查看设备底面铭牌，查找系统默认用户名和密码。

在登录界面选择 **System User** 对应的账户，输入密码后登录。

![1725868838155-cbb2837b-e079-4c9f-ab8f-f82201f955d4.png](./img/bXu8tvlaMDuH9WMP/1725868838155-cbb2837b-e079-4c9f-ab8f-f82201f955d4-891604.webp)

![1725342890143-ea95a961-841d-44fa-bedb-e79334972a9c.png](./img/bXu8tvlaMDuH9WMP/1725342890143-ea95a961-841d-44fa-bedb-e79334972a9c-454757.webp)

![1725869733689-f5dfd94f-ce8c-4f42-a6df-7e7ec32b8a98.png](./img/bXu8tvlaMDuH9WMP/1725869733689-f5dfd94f-ce8c-4f42-a6df-7e7ec32b8a98-680700.webp)

**方式二：SSH 远程连接**

使用 SSH 连接设备前，需保证设备网络可访问。查看设备底面铭牌，查找系统默认以太网地址，将 PC 配置为与设备同一网段。

打开 SSH 终端工具（以 MobaXterm 为例），输入设备地址点击连接。

![1725869872365-80e4f591-735e-4a8c-9855-ce5ea9868975.png](./img/bXu8tvlaMDuH9WMP/1725869872365-80e4f591-735e-4a8c-9855-ce5ea9868975-445078.webp)

根据提示内容，输入默认账户和密码。

![1725427512036-06b2508d-df93-4bca-aed0-c6d9c4e46625.png](./img/bXu8tvlaMDuH9WMP/1725427512036-06b2508d-df93-4bca-aed0-c6d9c4e46625-229025.webp)

---

### 装完自检

- ☐ 设备已固定（导轨或壁挂）。  
- ☐ 电源、网线已接好；若用蜂窝，SIM 与天线已就位。  
- ☐ **PWR 红灯常亮**且 **STATUS 绿灯慢闪**。  
- ☐ HDMI 或 SSH 已能正常登录系统。

如无法登录或灯态异常，请检查接线与供电。恢复出厂操作见 §2.7。

### 2.3 指示灯与复位键

#### 2.3.1 运行状态指示灯

![1748508489416-b15b5a18-a3c6-4d33-9cf3-02b1523affe6.jpeg](./img/bXu8tvlaMDuH9WMP/1748508489416-b15b5a18-a3c6-4d33-9cf3-02b1523affe6-322761.webp)

| 标识 | 名称 | 定义 |
| --- | --- | --- |
| PWR | 电源指示灯 | 红色 LED。亮起表示系统处于开机状态；熄灭表示系统处于关机状态。 |
| STATUS | 系统运行状态指示灯 | 绿色 LED。约 **1 Hz 慢闪** 表示系统运行正常；熄灭表示系统未运行。 |
| USER | 用户可编程指示灯 | 绿色 LED。可由用户编程实现 LED 状态逻辑。 |
| 4G/5G | 蜂窝网连接状态指示灯 | 绿色 LED。常亮表示蜂窝网络连接成功；闪烁表示蜂窝网络未连接。 |

> **闪烁频率定义**：常亮/常灭指至少保持约 3 s；慢闪约 1 Hz；快闪约 5 Hz。

#### 2.3.2 蜂窝信号状态灯

EC3000 的 **4G/5G** 指示灯仅指示蜂窝网络连接状态，无信号格数分级显示。

| 灯态 | 含义 |
| --- | --- |
| 常亮 | 蜂窝网络连接成功 |
| 闪烁 | 蜂窝网络未连接 |

#### 2.3.3 复位键与开关机键

**RESET 针孔按键**

![1748577082636-22f0a14a-9f8d-47e2-94cf-f4dc6cc0de9a.jpeg](./img/bXu8tvlaMDuH9WMP/1748577082636-22f0a14a-9f8d-47e2-94cf-f4dc6cc0de9a-229506.webp)

RESET 按键用于硬件恢复出厂，位于右面板（见 §2.2.2）。恢复出厂的详细步骤见 §2.7。

**ON/OFF 开关机按键**

![1748577162795-a0d87de5-ba59-416e-99be-9f9e55cd060f.jpeg](./img/bXu8tvlaMDuH9WMP/1748577162795-a0d87de5-ba59-416e-99be-9f9e55cd060f-009092.webp)

- 系统正常运行时**轻触** ON/OFF 按键，系统将提示是否关机，在显示器上点击确认将关闭系统（倒计时 60 秒内未选择将强制关机）。
- 系统正常运行时**长按** ON/OFF 按键 6 秒以上将强制关机。
- 系统关闭时**轻触** ON/OFF 按键，系统将启动。

### 2.4 机械安装

#### 2.4.1 DIN 导轨

EC3000 的 DIN 导轨安装板附在下面板上。

1. 将 DIN 导轨安装板的上方挂钩卡入到 DIN 轨支架的顶端。
2. 缓慢向 DIN 轨支架方向向前推动设备，使得 DIN 轨底端卡入到位。

![1726621639249-b3ac993d-897c-4a80-8cd1-e2ad2f524001.jpeg](./img/bXu8tvlaMDuH9WMP/1726621639249-b3ac993d-897c-4a80-8cd1-e2ad2f524001-139958.webp)

#### 2.4.2 壁挂

EC3000 可以采用壁挂套件进行安装，套件需要单独购买。

先将套件用螺钉固定在设备的下面板上，再用螺钉将设备固定到墙面或柜体。

1. 使用螺钉将壁挂套件固定在 EC3000 的下面板上。
2. 当壁挂套件成功固定到 EC3000 以后，使用螺钉将 EC3000 固定在墙面或柜子上。

![1726621663940-2cb8fbf6-0d4f-49d9-97a0-084cfdea0066.png](./img/bXu8tvlaMDuH9WMP/1726621663940-2cb8fbf6-0d4f-49d9-97a0-084cfdea0066-021763.webp)

### 2.5 连接与布线

#### 2.5.1 以太网

EC3000 提供 2 个以太网接口。ETH1 为独立以太网接口，ETH2 接口为 2 个交换口。

![1748507720864-2a1b0709-f19c-4bba-8002-99417c573404.jpeg](./img/bXu8tvlaMDuH9WMP/1748507720864-2a1b0709-f19c-4bba-8002-99417c573404-538810.webp)

每个网口上方各有 2 个 LED 灯：

**绿色 LED（速率指示）**

| 状态 | 含义 |
| --- | --- |
| OFF | 1. 无连接<br/>2. 速率 10 Mbps<br/>3. 速率 100 Mbps |
| ON | 速率 1000 Mbps |
| Blinking | — |

**橙色 LED（通信指示）**

| 状态 | 含义 |
| --- | --- |
| OFF | 1. 无连接<br/>2. 端口无数据活动 |
| ON | — |
| Blinking | 端口有数据活动 |

> 在网络 Link up 后，且接口速率为 1000 Mbps 时绿色 LED 亮起；在网络 Link up 时若有数据通信则橙色 LED 闪烁。

#### 2.7.1 HDMI 直连登录

#### 2.7.3 恢复出厂

RESET 针孔按键位于右面板（见 §2.2.2）。

1. **运行中恢复**：在系统正常运行时按住 RESET 约 10 秒，等待 STATUS 灯由闪烁变为常亮后松开，设备将进入系统重置状态（恢复为出厂状态）。
2. **上电前恢复**：在上电之前按住 RESET 键，然后上电，持续按住约 5 秒，直到 STATUS 灯长亮后 5 秒内松开，设备将进入系统重置状态（恢复为出厂状态）。
