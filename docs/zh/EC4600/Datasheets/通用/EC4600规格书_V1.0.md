# <span style="color: green;">1. 产品概述</span>

**EC4600 AI边缘计算机专为实时视觉识别和本地图像分析打造，提供14 TOPS边缘AI算力。**


**产品特点：**
- **14 TOPS AI算力:** 八核ARM、Adreno GPU，主频最高2.7 GHz
- **视觉接口丰富:** 4路摄像头供电、HDMI、USB、扬声器
- **灵活联网:** 4G、Wi-Fi 6、6×FE、双SIM故障切换
- **工业可靠:** 金属机身、IP40、无风扇、宽温设计
- **运行保障:** 软硬件看门狗、多级链路检测
