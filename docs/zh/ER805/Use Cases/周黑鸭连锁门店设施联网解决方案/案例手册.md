# 连锁门店设施联网方案

## 一、方案概述

### 1.1 项目背景

随着连锁业务的飞速发展，连锁门店遍布全国各地，连锁门店的网络业务稳定性与集团总部业务息息相关。如何构建一个稳定、安全、标准化的业务网络成为连锁店IT网络建设的重中之重。

目前某连锁企业拥有大量的直营店和加盟店，日常的网络管理成为重点工作，门店业务网络中断会影响业务交易，造成企业盈利损失，甚至给顾客带来较差的购物体验。那么保持网络稳定，出现故障问题如何快速定位以及恢复问题至关重要。

连锁门店的数量会随着企业飞速发展的脚步极速扩展，IT团队需要在短时间内快速完成众多门店的联网部署工作，对IT团队带来极大的挑战。

目前连锁分支门店地理位置分布零散，数量众多，日常的运营维护成本高，连锁企业需要迫切解决如何高效、实时的管理众多门店网络。

为此，映翰通结合自身优势，针对某连锁企业武汉800多家连锁门店的应用场景，推出星汉—云管理网络解决方案，包括边缘路由器ER805与小星云管家SaaS服务构成，助力该连锁企业实现门店网络高效管理。

### 1.2 建设目标

- 提供高速、安全、可靠不间断的网络连接，实现实时通信
- 实现门店网络稳定运行，快速定位及恢复故障
- 在短时间内快速完成众多门店的联网部署工作
- 实现高效、实时的管理众多门店网络
- 减轻大规模网络设备管理工作量

### 1.3 适用场景

- 连锁门店网络建设
- 直营店/加盟店联网
- 零售门店数字化改造
- 商业机构分支网络管理
- 企业SD-WAN组网

## 二、需求分析

### 2.1 设备现状

- 设备类型：门店电视系统、扫码枪、收费系统、POS机、门店摄像头、员工/顾客电脑手机等
- 通信接口：以太网、Wi-Fi、4G/5G
- 通信协议：SD-WAN、VPDN
- 部署环境：连锁门店（800多家），分布零散
- 数量规模：大规模连锁门店网络

### 2.2 核心需求

1. **网络稳定性需求**：提供高速、安全、可靠不间断的网络连接，实现实时通信
2. **冗余备份需求**：支持双卡备份、链路备份、负载均衡、策略路由等功能
3. **数据安全需求**：支持VPDN，保证数据交互的安全性
4. **网络性能需求**：网络通道具备高稳定性、低延时、高带宽的特性
5. **部署便捷需求**：配置简单，无需专业工程师上门调试，门店员工即可安装配置
6. **SD-WAN需求**：支持SD-WAN，实现总部与分支门店的网络互通及统一管理
7. **云端管理需求**：支持云端管理，减轻大规模网络设备管理工作量

## 三、总体架构设计

该方案包含门店电视系统、扫码枪、收费系统、ER805、星汉—云管理平台和集团数据中心等部分。ER805边缘路由器作为现场网络承载设备，通过4G/5G蜂窝网络、有线网络等快速接入互联网，提供稳定高效的业务网络。

ER805可以便捷组建高效的局域网，门店内的电视系统、扫码枪、收费系统、门店摄像头以及员工/顾客的电脑、手机等设备通过以太网或者Wi-Fi简单便捷地接入业务局域网中，电视系统实时同步运营中心服务器的产品图片、实时价格、优惠活动等信息；扫描枪、收费系统、POS机等设备的数据实时同步至运营中心服务器；摄像头画面实时同步至本地NVR和运营中心；同时可以通过5.8G WiFi为顾客提供高速地无线网络，进而为顾客提供高效、舒适的购买及结账体验。同时ER805边缘路由器通过星汉—云管理平台一键实现SD-WAN组网，轻松完成总部与分支门店的网络互通和统一管理。

### 3.1 四层架构

![拓扑图](./images/320f5d3d.webp)

1. **感知层**：门店电视系统、扫码枪、收费系统、POS机、门店摄像头、员工/顾客设备等
2. **网络层**：ER805边缘路由器，支持4G/5G、有线网络、Wi-Fi、SD-WAN
3. **平台层**：星汉—云管理平台、集团数据中心/运营中心服务器
4. **应用层**：产品信息同步、交易数据处理、视频监控、顾客Wi-Fi服务、集中管理

### 3.2 数据流

门店设备 → ER805路由器 → 4G/5G/有线网络 → 运营中心服务器/数据中心

SD-WAN组网：总部 ←→ ER805（星汉云平台）←→ 各分支门店

## 四、网络与接入方案

### 4.1 联网方式选型

采用4G/5G蜂窝网络、有线网络等多链路接入方式，支持双卡切换、有线/无线链路备份、负载均衡、策略路由等，保障设备网络通信不间断。

### 4.2 边缘网关选型要点

**ER805边缘路由器特性**：

- 支持4G/5G高速蜂窝网络，最大下行速率2Gbps，支持SA和NSA组网
- 冗余链路设计，支持双SIM切换，有线/无线链路备份，负载均衡，策略路由等
- 高可靠性设计，支持多链路备份、逐流负载均衡和故障转移
- 实时探测链路的时延、抖动、丢包、信号强度等参数，确保重要业务流量始终从最优链路转发
- 支持千兆Wi-Fi网络，最大连接速率为1300Mbps，2.4G和5.8G WiFi双频并发，支持AP/STA模式
- 搭配千兆以太网接口，支持1WAN/4LAN或2WAN/3LAN工作模式
- 支持VPDN，保证数据交互的安全性
- 支持防火墙，访问控制功能，可按需设置黑白名单，允许指定IP联网
- 支持SD-WAN，只需要在小星云平台将设备加入SD-WAN网络，设备可自动建立隧道，快速构建分支间安全可靠的网络连接
- 云端一体化设计让部署更简单便捷，仅需简单的操作即可完成部署工作
- 支持接入星汉-云网络管理平台，实现集中式远程管理部署，掌控现场
- 配置简单，无需专业工程师上门调试，门店员工即可安装配置

## 五、协议与数据采集方案

### 5.2 北向协议支持

- 支持接入星汉-云网络管理平台
- 支持SD-WAN自动隧道建立
- 支持集中式远程管理部署
