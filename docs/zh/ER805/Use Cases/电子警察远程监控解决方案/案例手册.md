# 移动卫兵——电子警察远程监控解决方案

## 一、方案概述

### 1.1 项目背景

某智能交通企业与某城市交警部门合力打造"5G+移动卫兵"方案，帮助交警监管部门对监控区域情况进行全天24小时监控，并可通过远程实时监控来提高服务管理水平，实现预控目标，合理安排抽巡查计划，使监管更具实效性与针对性，让各类重点区域逐渐向"无人值守"、"少人值守"运行管理模式推进。

利用5G网络高带宽、低延时、安全、可靠稳定的特性，将前端图像实时上传至监控中心和手机移动端等设备上，并与现有的视频监控网络相融合，形成统一协调的动态视频指挥系统。监控系统作为安防的第一线安防设备也已广泛部署，然而地处偏僻的监控区域往往面临着难以提供电力供应以及网络供应的问题，类似于应急场所监测、工地监测等复杂的环境布线要耗费相当大的人力物力，并且存在安全隐患。

因此移动卫兵监控的部署方案成为了最佳的选择，内置电池加上太阳能辅助供电即可摆脱有线电缆的诸多限制，而无线5G传输方式也能够在任何有运营商信号覆盖的地方任意部署，是交警、公安、应急、安防、维稳等领域真正意义上的哨兵。目前，该城市交警部门已部署在现场的5G移动卫兵共计80台，在未来十年，随着远程监控需求的不断增长，预计会陆续部署1万台以上。

### 1.2 建设目标

- 对监控区域情况进行全天24小时监控
- 通过远程实时监控提高服务管理水平
- 实现预控目标，合理安排抽巡查计划
- 使监管更具实效性与针对性
- 推动各类重点区域向"无人值守"、"少人值守"运行管理模式推进
- 将前端图像实时上传至监控中心和手机移动端
- 与现有视频监控网络相融合，形成统一协调的动态视频指挥系统

### 1.3 适用场景

- 电子警察远程监控
- 交通治安监控
- 应急场所监测
- 智慧工地监控
- 反恐、抢险救灾现场监控
- 大型集会安保监控
- 石油天然气行业监控
- 部队训练监控

## 二、需求分析

### 2.1 设备现状

- 设备类型：移动卫兵一体化设备（内置蓄电池、太阳能板、抓拍设备、车型检测、车牌识别系统）
- 通信接口：以太网、4G/5G
- 通信协议：VPDN专网
- 部署环境：施工现场、交通路口、应急场所、工地、偏远监控区域，移动部署
- 数量规模：已部署80台，预计部署1万台以上

### 2.2 核心需求

1. **施工监控需求**：通过移动监控实时监测施工进度和工人安全的情况，在发现异常时能够快速进行预警，保证生命财产安全
2. **智能交通需求**：搭载车型检测、车牌识别、车辆管控等新一代信息技术，保障交通安全、发挥交通基础设施效能、提升交通系统运行效率和管理水平
3. **远程维护需求**：支持远程维护设备，对接交警管理平台，提供强大的数据支撑
4. **网络备份需求**：支持双SIM卡备份，保障网络通讯不间断
5. **定时管理需求**：支持定时重启功能，用户可按需启用
6. **环境适应需求**：设备符合全工业设计，在严苛环境下也能长时间稳定运行
7. **数据安全需求**：支持VPDN，方便与交通部门的无缝对接，保证数据的安全性
8. **高速网络需求**：高带宽、低延时、安全、可靠稳定的5G网络，实时快速监控移动卫兵的运行状态

## 三、总体架构设计

该方案包含移动卫兵、ER805和交管监控中心等部分组成。在政府部门现场执法、石油天然气行业、交通治安、部队训练、反恐、抢险救灾、智慧工地、大型集会等地点部署移动卫兵进行实时监控。

移动卫兵通过以太网与ER805连接，通过4G/5G运营商网络将数据通过VPDN通道安全传输至交警部门平台。维护人员通过VPDN专网可直接访问现场的路由器，对路由器进行远程配置、调试和升级。

移动卫兵可提供电脑客户端软件、手机APP以及现场控制的数字触摸屏键盘，以此来掌握实时路况信息，进行实时远程监控和指定时间地点的录像调取等操作。

### 3.1 四层架构

![拓扑图](./images/40103f00.webp)

1. **感知层**：移动卫兵一体化设备（蓄电池、太阳能板、抓拍设备、车型检测、车牌识别系统）
2. **网络层**：映翰通ER805 5G边缘路由器，支持双SIM卡、4G/5G、VPDN专网
3. **平台层**：交管监控中心、交警部门平台
4. **应用层**：实时监控、远程配置调试升级、录像调取、路况信息掌握、车型检测、车牌识别

### 3.2 数据流

移动卫兵（抓拍/检测）→ ER805路由器（4G/5G、VPDN加密）→ 交警部门平台 → 监控中心/手机APP/电脑客户端

远程维护：维护人员 → VPDN专网 → ER805 → 远程配置/调试/升级

## 四、网络与接入方案

### 4.1 联网方式选型

采用5G/4G高速蜂窝网络接入方式，支持双SIM卡备份，通过VPDN专网通道安全传输数据。无线5G传输方式能够在任何有运营商信号覆盖的地方任意部署。

### 4.2 边缘网关选型要点

**ER805 5G边缘路由器特性**：

- 支持双SIM卡备份，保障网络通讯不间断
- 支持定时重启功能，用户可按需启用
- 全工业设计，在严苛环境下也能长时间稳定运行
- 支持VPDN，方便与交通部门的无缝对接，保证数据的安全性
- 高带宽、低延时、安全、可靠稳定的5G网络
- 5G高速蜂窝网络接入，高速局域网组网
- 支持5*千兆端口，可划分VLAN
- 支持千兆Wi-Fi 1200M，2.4G和5G双频并发
- 工业化设计，稳定可靠，提供高可用性的数据传输服务，满足移动场景的挑战
- 支持SD-WAN，提供优质数据链路，实现负载均衡冗余，链路备份，保障设备网络通信不间断
- 通过CE、FCC、IC、PTCRB、AT&T、Verizon等认证，适用全球范围

## 五、协议与数据采集方案

### 5.1 支持协议

- **网络协议**：5G、4G、双SIM卡、千兆以太网、Wi-Fi 1200M（2.4G和5G双频）
- **安全协议**：VPDN虚拟专用网
- **管理协议**：SD-WAN

### 5.2 北向协议支持

- 支持VPDN专网接入交警部门平台
- 支持远程配置、调试、升级
- 支持电脑客户端软件、手机APP接入

## 六、方案亮点总结

1. **移动卫兵功能特点**：

   - 智能监控作战效率高：自带蓄电池、太阳能板、抓拍数据信息支持断点续传，可实现24h不间断监控
   - 适应能力强：移动监控不受网、电的限制，车体灵活，单人即可布防，对于分散、复杂环境的地区和需要临时部署的环境比有线监控更加有利

2. **高带宽低延时**：ER805高带宽、低延时的网络特性，为移动卫兵的应用场景提供稳定、可靠的网络通道

3. **5G高速网络**：5G高速蜂窝网络接入，高速局域网组网，支持5*千兆端口，可划分VLAN，支持千兆Wi-Fi 1200M，2.4G和5G双频并发

4. **双SIM卡备份**：支持双SIM卡备份，保障网络通讯不间断

5. **SD-WAN技术**：支持SD-WAN，提供优质数据链路，实现负载均衡冗余，链路备份，保障设备网络通信不间断

6. **VPDN安全保障**：支持VPDN，方便与交通部门的无缝对接，保证数据的安全性

7. **工业级可靠性**：全工业设计，在严苛环境下也能长时间稳定运行，满足移动场景的挑战

8. **全球认证**：通过CE、FCC、IC、PTCRB、AT&T、Verizon等认证，适用全球范围

9. **灵活部署**：内置电池加上太阳能辅助供电即可摆脱有线电缆的诸多限制，而无线5G传输方式也能够在任何有运营商信号覆盖的地方任意部署

10. **多平台支持**：可提供电脑客户端软件、手机APP以及现场控制的数字触摸屏键盘，掌握实时路况信息，进行实时远程监控和指定时间地点的录像调取
