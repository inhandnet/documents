# 企业分支联网解决方案

## 一、方案概述

### 1.1 项目背景

随着企业或品牌分支门店传统宽带业务高额成本，各大企业及连锁品牌急需降本，寻求稳定可靠的企业分支联网方案，且需搭建SD-WAN网络，实现分支端与中心端流量互通与强制转发。

本方案旨在实现设备统一接入、为设备提供网络、远程控制、状态监控、异常告警、SD-WAN组网，为企业等提供稳定可靠的物联网底座。

### 1.2 建设目标

- 设备全量联网，统一接入管理

- 搭建SD-WAN网络

- 支持远程配置、远程诊断、远程升级

- 实现告警、联动、可视化、报表分析

- 提升运维效率，降低人工巡检成本

- 安全稳定、易扩展、易维护

### 1.3 适用场景

- 企业/门店设备联网（电脑、手机、扫码枪、摄像头）

- SD-WAN组网

## 二、需求分析

### 2.1 设备现状

- 设备类型：民用设备为主

- 通信接口：Ethernet/4G/5G/Wi-Fi/

- 部署环境：室内 

### 2.2 核心需求

    1.网络需求：有线 / 4G/5G 备份，低流量、高稳定

    2.远程需求：远程调试、远程控制、远程维护

    3.SD-WAN组网需求：中心端建立SD-WAN Server、分支端建立SD-WAN通道

    4.平台需求：大屏可视化、报表

## 三、总体架构设计

### 3.1 四层架构

1.感知层：电脑、扫码枪、手机、摄像头

2.网络层：边缘路由器、4G/5G、以太网、WIFI、中心端路由器

3.应用层：监控大屏、Web 管理后台、告警系统、企业数据中心

### 3.2 数据流

设备→ 边缘侧路由器 → 4G/5G → SD-WAN通道 → 中心端路由器 → 数据展示

## 四、网络与接入方案

### 4.1 联网方式选型

蜂窝

### 4.2 边缘路由器选型要点

- 千兆以太网口

- WIFI

- 支持4G/5G
- 支持SD-WAN组网

- 工业级宽温、防尘、抗干扰

- 远程管理、远程升级、远程配置

## 五、方案亮点总结

1. 一站式：接入 + 网络 + 平台 + 应用全栈解决方案

2. 高兼容：多设备、多网络统一接入

3. 低成本：减少人工巡检，提升运维效率

4. 安全合规：传输加密、权限管理、操作审计
