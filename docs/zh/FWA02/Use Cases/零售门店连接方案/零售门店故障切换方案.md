# 零售门店联网解决方案

## 1. 方案概述

### 1.1 项目背景

随着连锁零售商在全国范围扩张，网络可靠性直接影响门店核心业务的运转——POS 交易、视频监控和实时数据同步。单链路有线 WAN 故障可能中断收银体验并造成收入损失。本方案解决两大关键挑战：通过自动 WAN + 5G 蜂窝（Cellular）故障切换确保每家门店**始终在线**，并让总部 IT 团队能够通过单一平台**远程管理**数百家门店。

### 1.2 目标

- 实现无缝的 WAN + 5G 蜂窝故障切换，业务不中断
- 即插即用部署——门店员工无需工程师到场即可完成安装
- 通过 InCloud Manager 实现集中式远程管理，实时掌握全网状态
- 借助 VPN 加密与多层防火墙保障数据传输安全

### 1.3 应用场景

- 连锁零售门店 / 便利店 / 超市
- 加盟与直营门店网络标准化
- 分布式门店集中运维（O&M）管理

## 2. 需求分析

### 2.1 现有设备环境

| 项目 | 说明 |
|------|------|
| 设备类型 | POS 终端、条码扫描枪、支付系统、数字标牌、IP 摄像头、员工/顾客终端 |
| 接口 | 以太网、Wi-Fi、4G/5G |
| 部署环境 | 室内零售门店，地理分布广泛 |
| 规模 | 大规模（数百至数千家门店） |

### 2.2 核心需求

1. **永远在线的连接** —— 当有线 WAN 降级或故障时，自动切换至 5G 蜂窝；恢复后自动回切
2. **简易部署** —— 门店员工自助安装；通过云端实现零接触配置（Zero-Touch Provisioning）
3. **集中管理** —— 总部 IT 实时監控所有门店；远程排障，无需上门
4. **数据安全** —— 通过 VPN 隧道与防火墙策略保护交易数据
5. **高性能 Wi-Fi** —— 为员工终端和顾客设备提供稳定的无线接入

## 3. 架构设计

### 3.1 四层架构

| 层级 | 组成 |
|------|------|
| **感知层** | POS 终端、条码扫描枪、支付系统、数字标牌、IP 摄像头、员工/顾客终端 |
| **网络层** | FWA02（有线 WAN 主链路 + 5G 蜂窝备份，Wi-Fi 6） |
| **平台层** | InCloud Manager SaaS、总部数据中心 / 运营中心 |
| **应用层** | 交易处理、商品信息同步、视频监控、访客 Wi-Fi、集中运维 |

### 3.2 数据流向

```
门店设备
   └→ FWA02
         ├─ 主链路 : 有线 WAN（宽带）──────────┐
         └─ 备份链路 : 5G 蜂窝（自动故障切换）────┴→ 总部数据中心 / 运营服务器
                                                                    ↕
                                                        InCloud Manager（云端）
                                                                    ↕
                                                          总部 IT 管理控制台
```

**故障切换逻辑：** FWA02 持续监测 WAN 链路质量（延迟、抖动、丢包）。一旦检测到链路降级或故障，即自动切换至 5G 蜂窝。当有线链路恢复后，设备自动回切至主链路——无需人工干预。

---

## 4. 网络与接入方案

### 4.1 连接设计

**主链路 —— 有线 WAN：** 2.5 GbE 宽带连接，提供高带宽、低延迟，满足门店日常运营需求。

**备份链路 —— 5G 蜂窝：** 5G SA/NSA，下行最高 4.76 Gbps / 上行 1.25 Gbps，并自动回退至 4G LTE Cat 19（下行 1.6 Gbps）。支持双 Nano SIM + eSIM，可灵活切换运营商，最大限度保障备份可靠性。

### 4.2 FWA02 设备规格

| 类别 | 规格 |
|------|------|
| **以太网** | 2 × 2.5 GbE RJ45，WAN/LAN 可切换 |
| **5G 速率** | 下行 4.76 Gbps / 上行 1.25 Gbps（SA & NSA） |
| **4G 回退** | LTE Cat 19，下行 1.6 Gbps / 上行 200 Mbps |
| **SIM** | 1 × eSIM + 2 × Nano SIM（热插拔） |
| **Wi-Fi** | Wi-Fi 6（802.11ax），2.4G + 5.8G 双频，最高 3600 Mbps |
| **最大用户数** | 220 台设备（128 台 Wi-Fi） |
| **防火墙吞吐** | 2 Gbps |
| **链路监测** | 实时检测延迟、抖动、丢包 |
| **VPN** | IPSec VPN、L2TP VPN |
| **防火墙** | MAC / IP / 端口 / 协议过滤，访问控制，端口映射 |
| **工作温度** | -10°C 至 50°C |
| **认证** | FCC、IC、PTCRB、Verizon、T-Mobile、CE |
| **质保** | 3 年 |

## 5. 云端管理 —— InCloud Manager

FWA02 原生集成 **InHand InCloud Manager**，这是一款用于集中管理分布式零售门店网络的 SaaS 平台。

| 功能 | 说明 |
|------|------|
| **集中仪表盘** | 单视图查看所有门店设备、接口状态与流量 |
| **零接触部署** | 设备上电后自动注册到云端——无需现场配置 |
| **实时监控** | 链路延迟、抖动、丢包、吞吐，以及蜂窝信号（RSSI / RSRP / RSRQ / SINR） |
| **告警** | 设备离线、链路切换、异常事件邮件告警 |
| **远程运维** | Web UI / CLI 远程接入；Ping / Traceroute / 抓包远程诊断 |
| **批量管理** | 跨数百家门店批量升级固件、推送配置 |
| **配置备份** | 导入 / 导出配置模板，快速复制门店上线 |

## 6. 安全

| 安全能力 | 实现方式 |
|----------|----------|
| 加密传输 | 门店与总部数据中心之间建立 IPSec / L2TP VPN 隧道 |
| 访问控制 | 基于 MAC、IP、端口、协议的多维防火墙过滤 |
| Wi-Fi 安全 | 增强型 Wi-Fi 安全；员工网络与访客网络逻辑隔离 |
| 自愈能力 | 内置软硬件看门狗，实现自主故障恢复 |
