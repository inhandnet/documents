# IG502 - IEC 60870-5-101 至 IEC 60870-5-104 协议转换

**产品型号：** IG502（InGateway 502）

## 1. 概述

在电力公用事业、智能电网、水务 / 燃气 / 热力管网及其他工业控制环境中，仍有大量已投运的 RTU（Remote Terminal Unit，远程终端单元）、保护继电器、IED（Intelligent Electronic Device，智能电子设备）和计量装置采用 **IEC 60870-5-101**（简称 IEC 101）通信——这是一种面向串行、字节型远动协议，适用于低带宽链路（RS-232 / RS-485 / 光纤调制解调器）。

然而，现代 SCADA（Supervisory Control and Data Acquisition，数据采集与监控） / DMS（Distribution Management System，配电管理系统） / EMS（Energy Management System，能量管理系统）主站以及云端监控平台普遍采用 **IEC 60870-5-104**（简称 IEC 104）——该标准基于 TCP/IP 的同一远动协议（使用 2404 端口）。

映翰通 **IG502 边缘网关** 架起了这两个世界之间的桥梁。它在串行侧充当 IEC 101 主站，在以太网 / 蜂窝侧充当 IEC 104 服务器，透明地转换报文——同时保留 Type ID、信息对象地址（IOA，Information Object Address）、传送原因（COT，Cause of Transmission）和 ASDU（Application Service Data Unit，应用服务数据单元）地址——从而使现有 legacy 设备无需更换即可接入现代 IP 化 SCADA 系统。

本文档描述了 IG502 在此类项目中的应用场景、系统架构与核心价值。

## 2. 背景与痛点

### 2.1 现实现状

现场资产如变电站 RTU、馈线终端单元（FTU，Feeder Terminal Unit）、配电变压器终端单元（TTU，Distribution Transformer Terminal Unit）、柱上重合器和较老型号的保护 IED 往往已在多年前——甚至十几年前——安装。它们通常具备：

- **RS-232 / RS-485 / RS-422** 串口
- **IEC 60870-5-101** 应用协议（平衡式或非平衡式）
- 1200 / 2400 / 9600 / 19200 bps 波特率
- 专用线缆和短距光纤调制解调器

为了获得原生 IEC 104 连接能力而更换这些设备，通常并不可行——不仅涉及资本支出（CAPEX），更因为接触关键一次设备会带来运行风险。

### 2.2 现代化需求

与此同时，控制中心正在经历现代化改造：

- 主站从专用串口分线柜迁移至 **IP 化 SCADA / DMS** 平台
- 集中式遥测成为 **故障定位、隔离与恢复（FLISR，Fault Location, Isolation and Service Restoration）** 的必需能力
- **网络安全**标准（IEC 62351、NERC CIP 等）要求网络分段、认证和审计日志——这些对 IP 网络顺理成章，对原始串口却难以实现
- **蜂窝（4G / 5G）回传**被用于连接无人值守、地理分散的站点
- **云 / 边缘分析**需要统一的北向数据平面

### 2.3 鸿沟

IEC 101 与 IEC 104 之间的协议转换鸿沟，是将棕地（brownfield）资产接入绿地（greenfield）SCADA 基础设施的最大障碍。专用协议转换网关正是为了解决这一鸿沟而设计。

## 3. 方案概述

### 3.1 IG502 的角色

IG502 部署在 field 边缘，同时承担三种角色：

1. **IEC 101 主站**：通过 RS-232 / RS-485 串口轮询一个或多个下游 IEC 101 子站（outstation）。
2. **IEC 104 服务器**：通过以太网（或蜂窝广域网）端口接受上游 SCADA 主站在 TCP/2404 上的连接。
3. **边缘路由器**：提供 4G / 5G / 有线上行链路、VPN、防火墙和远程管理。

由于 IG502 保持 IEC 101 / 104 数据模型完全一致（Type ID、IOA、COT、ASDU 地址一一对应），SCADA 主站看到的 legacy 设备 **就像原生支持 IEC 104 一样**。

### 3.2 参考架构

```
┌──────────────────────┐     RS-485       ┌──────────────┐     Ethernet / 4G      ┌──────────────────┐
│  IEC 101 Outstations │ ───────────────► │   IG502      │ ─────────────────────► │  IEC 104 SCADA   │
│  (RTU / IED / FTU)   │   IEC 60870-5-101│   Gateway    │  IEC 60870-5-104 (2404)│  Master Station  │
└──────────────────────┘                  └──────────────┘                        └──────────────────┘
                                          │   Protocol   │
                                          │   conversion │
                                          │ + edge router│
```

四层模型：

| 层级 | 组成 | 作用 |
|------|------|------|
| 现场 / 感知层 | RTU、IED、FTU、TTU、重合器、电能表 | 生成遥测 / 接受控制（IEC 101） |
| 边缘 / 网关层 | **IG502** | 轮询 IEC 101、暴露 IEC 104、缓存、安全、路由 |
| 传输层 | 有线以太网、4G / 5G、可选 VPN | 将 IEC 104 流量传输至控制中心 |
| 应用层 | SCADA / DMS / EMS / 云 HMI | 消费 IEC 104 数据，驱动仪表盘与控制 |

### 3.3 IEC 101 与 IEC 104 对比——标准一览

| 方面 | IEC 60870-5-101（串行） | IEC 60870-5-104（TCP/IP） |
|------|--------------------------|--------------------------|
| 物理层 | RS-232 / RS-485 | 以太网 / 4G / 5G |
| 链路层 | FT 1.2 帧，平衡式 / 非平衡式 | TCP，APCI（启动 / 停止 / 测试） |
| ASDU | Type ID 相同（M_SP_NA_1、M_DP_NA_1、M_ME_NC_1、C_SC_NA_1 等） | Type ID 相同 |
| 应用数据 | 通过网关端到端保留 | 通过网关端到端保留 |
| 典型 TCP 端口 | 不适用 | 2404 |

IG502 桥接了链路层和物理层的差异，同时保持应用层数据模型不变——这正是为 IEC 104 开发的 SCADA 点表可继续用于 legacy IEC 101 设备的原因。

## 4. 应用场景

### 4.1 智能电网——配电自动化

**痛点：** 某条馈线上仍有数百台柱上 FTU 和 TTU 通过串口使用 IEC 101 通信，而新的配电主站仅支持 IEC 104。

**方案：** 每个站点（或每个环网柜）部署一台 IG502。串口侧连接 FTU；蜂窝侧通过 APN 专网 4G 上报至主站。现有 FTU 可在其整个经济生命周期内继续服役。

**收益：** 无需更换一次设备，单站调试时间以分钟计，故障数据实时到达调度员。

### 4.2 变电站改造

**痛点：** 户内 / 户外变电站中的 legacy 保护 IED 由 IEC 101 间隔控制器汇聚。电力公司希望在不重新布线间隔的情况下实现集中监控。

**方案：** 在变电站通信柜中部署 IG502。RS-485 连接间隔控制器；通过光纤以太网（或 4G 备用）上行至区域控制中心，使用 IEC 104。

**收益：** 即插即用式现代化；变电站表现为原生 IEC 104 RTU；冗余 WAN（有线 + 4G）提升可用性。

### 4.3 可再生能源——光伏 / 风电场

**痛点：** 逆变器、汇流箱和气象站暴露 IEC 101 接口；而区域运营中心的 SCADA / 能量管理系统仅支持 IEC 104。

**方案：** 每个逆变器区或每个升压站 skid 部署一台 IG502；将 IEC 101 遥测（有功功率、无功功率、故障、开关量）转换为 IEC 104；上行至运营商的云 SCADA。

**收益：** 全厂通过标准化 IP 传输实现可观性；便于网络安全加固（VPN、防火墙、基于角色的访问控制）。

### 4.4 水务、燃气与区域供热

**痛点：** 泵站、阀室和压力调节器使用串行 IEC 101；而公用事业公司的 IP 网络和 SCADA 期望 IEC 104。

**方案：** 杆装或柜装 IG502 实现协议转换，并在有线网络不可用时提供蜂窝回传。

**收益：** 单台多用途设备（路由器 + 协议网关 + 边缘计算）减少物料清单（BoM）和狭小机柜内的占用空间。

### 4.5 铁路与工业能源系统

**痛点：** 牵引变电站和大型工业现场的 IEC 101 RTU 购于十年前；新的 EMS 平台统一采用 IEC 104。

**方案：** IG502 位于 RTU 与 IT / OT 边界之间，北向暴露 IEC 104，并可选输出 MQTT 供 IT 分析使用。

**收益：** OT 数据被释放用于数字化举措，而不干扰安全关键的控制回路。

## 5. 方案亮点

1. **即插即用转换**——两侧 Type ID、COT 和 IOA 保持一致；无需重新配置 SCADA 点表。
2. **工业级硬件**——宽温、无风扇、DIN 导轨设计；适用于变电站和户外机柜。
3. **多上行链路**——千兆以太网、4G / 5G，支持链路备份和无缝切换。
4. **边缘计算与缓存**——Python / Docker 容器、本地缓存、WAN 中断时的存储转发。
5. **安全设计**——IPsec / OpenVPN / L2TP、防火墙、RBAC（Role-Based Access Control，基于角色的访问控制）、签名固件，可选支持 IEC 62351 兼容的 TLS 部署。
6. **远程管理**——通过映翰通设备管理云平台（InHand Device Manager Cloud）实现批量配置、监控、固件更新和远程排障。
7. **已验证的互操作性**——经过与广泛使用的 IEC 101 和 IEC 104 主站 / 子站系统的验证。

## 7. 部署概要

1. **现场勘察**：识别 RTU / IED、串口参数和 IEC 101 帧格式细节。
2. **选择上行链路**：有线以太网、4G，或双链路备份。
3. **端到端验证**：与客户 SCADA 主站完成联调。
4. **接入云平台**：将网关注册到映翰通设备管理云平台，实现长期运维。
