# 大型城市二次供水设施远程智能管理系统

## 一、方案概述

### 1.1 项目背景

某现代化城市是一座拥有1700万人口的现代化城市，是中国的经济特区，是改革开放的先驱。该市政府提出应率先实现自来水全城直饮，构建从"源头到龙头"的全流程饮用水安全保障体系，进一步提高市民获得感、幸福感、安全感。

为实现全市自来水直饮的目标，该市政府和某城市水务集团开展了庞大的优质饮用水入户工程和二次供水设施提标改造工程，完善供水基础设施"最后一公里"，提升供水水质和服务质量，不断满足人民日益增长的美好生活需要。

在二次供水设施提标改造和新建工程中，该水务集团提出要建设二次供水设施的"智能管理系统"，采用先进的物联网技术，实现二次供水设施统一的信息化、数字化管理，确保二次供水水质、水压和供水安全。同时，之前老旧的供水方式，没有办法对整个环节有效监控，减少浪费。水泵房需要实行无人值守，设备集中管理，需对传感器状态进行远程监控，对小区二次加压泵站运行工况进行实时远程监控，数据上云、同时可远程传回供水公司监控中心。

映翰通IG900边缘计算网关具有高性能、高可靠性，提供了网络应用更高的安全性。云平台具有低成本、高效率的后台数据存储技术，灵活的性能及功能可扩展、可升级架构，实现对前端接入设备的入网集中化管理。

### 1.2 建设目标

- 实现二次供水设施运行数据及视频信息的自动采集、传输监控、预警报警、远程控制、存储备份和统计分析等功能
- 完成对二次供水设施的运行维护管理工作
- 水泵房实行无人值守，设备集中管理
- 对传感器状态进行远程监控，对小区二次加压泵站运行工况进行实时远程监控
- 数据上云，同时可远程传回供水公司监控中心
- 进行管网监控自动化的升级，提升管网监控能力和可靠性，同时降低运营成本
- 全面提升二次供水设施的数字化、信息化水平

### 1.3 适用场景

- 城市二次供水设施监控管理
- 小区二次加压泵站监控
- 泵房无人值守系统
- 优质饮用水入户工程
- 供水基础设施"最后一公里"监控

## 二、需求分析

### 2.1 设备现状

- 设备类型：西门子PLC控制器、变频器、传感仪表、水泵机组、水质监测设备、环境传感器等
- 通信接口：WAN口、LAN口、有线专网、4G LTE
- 通信协议：S7通信协议、MQTT协议
- 部署环境：小区二次供水泵房、无人值守站点
- 数量规模：数千套二次供水设施

### 2.2 核心需求

1. **实时数据采集和解析**：

   - 水质信息：余氯、浊度、pH值等
   - 环境信息：温度、湿度、地面积水等
   - 设备信息：电流、电压、电量、温度等
   - 供水信息：进出水压力、进出水流量、水箱液位等

2. **远程控制功能**：

   - 水压自动控制
   - 水泵机组自动切换
   - 集水坑自动排水
   - 泵房水淹自动断电保护
   - 压力和液位传感器故障自动识别

3. **网络接入需求**：支持WAN口有线接入方式、LAN接口

4. **协议支持需求**：支持主流PLC协议解析，适配多种污水处理设备

5. **云平台接入需求**：支持AWS云平台接入

6. **时钟同步需求**：支持NTP时钟同步

7. **数据存储需求**：支持数据本地存储，数据断点续传，支持扩展TF卡

## 三、总体架构设计

本方案采用西门子PLC作为控制设备，映翰通的IG900边缘计算网关作为通讯设备，AWS作为基础云平台。IG900采用有线专网接入的方式，远程连接云平台。IG900与现场西门子1200PLC控制器连接，解析S7通信协议，对PLC数据进行采集，实现本地存储数据、本地查询，支持MQTT协议与云平台通讯，数据采集传输周期要求10秒，实现远程监控现场设备信息和远程控制。

云平台信息管理系统以可视化的用户界面，集成视频监控、设备维护管理、数据分析和报表统计等功能，对数千套接入系统的二次供水设施进行全生命周期的信息化管理。并根据各类生产数据的分析成果优化二次加压设施的管控模式。

### 3.1 四层架构

![拓扑图](./images/aa628f71.webp)

1. **感知层**：西门子PLC控制器、变频器、传感仪表、水泵机组、水质监测设备（余氯、浊度、pH值）、环境传感器（温度、湿度、地面积水）等
2. **网络层**：映翰通IG900边缘计算网关，支持有线专网接入和4G LTE无线网络接入
3. **平台层**：AWS基础云平台、信息管理系统，集成视频监控、设备维护管理、数据分析和报表统计
4. **应用层**：可视化用户界面、供水公司监控中心、设备全生命周期信息化管理、数据优化分析

### 3.2 数据流

现场传感器/PLC → IG900边缘计算网关（S7协议解析、本地存储、MQTT转换）→ AWS云平台 → 监控中心/可视化界面/数据分析

采集周期：10秒

## 四、网络与接入方案

### 4.1 联网方式选型

采用有线专网接入为主，4G LTE无线作为备份的接入方式。凭借全球部署的4G无线网络和多种宽带服务，提供随处可得的不间断的互联网接入。

### 4.2 边缘网关选型要点

**IG900边缘计算网关特性**：

- 支持WAN口、LAN接口，便于设备的接入与调试
- 支持有线/4G LTE无线网络接入，为设备上云提供随处可得的高速网络连接
- 支持主流PLC协议解析（如S7协议），适配多种设备
- 支持AWS云平台接入
- 支持NTP时钟同步
- 支持数据本地存储，内置FLASH 8GB eMMC，支持TF卡扩展（最大128G），支持断点续传
- 支持上千级设备的数据采集，能满足不同现场的数据采集需求
- 通过CE、FCC、PTCRB、CCC、Verizon Wireless、AT&T认证
- 全工业级设计，为现场无人值守的站点实现可靠、安全、稳定的数据传输链路

## 五、协议与数据采集方案

### 5.1 支持协议

- **工业协议**：支持S7等多种工业协议，满足二次供水泵房控制器的协议需求
- **物联网协议**：MQTT协议传输到云平台
- **网络协议**：有线专网、4G LTE
- **时钟协议**：NTP时钟同步

### 5.2 北向协议支持

- 支持MQTT协议与云平台通讯
- 支持对接多种IoT云平台以及本地SCADA等第三方数采平台
- 支持自定义网关与云端的应用层通讯协议

## 六、方案亮点总结

1. **边缘计算能力**：通过Python开发可实现边缘计算能力，进行数据分析处理，客户可自定义智能逻辑化处理，数据本地预处理，减少云端的负荷。支持灵活定义数据边缘处理逻辑，可在边缘侧提供实时响应、数据计算和数据过滤，减轻云端压力

2. **数据可靠性**：边缘计算网关支持断点续传，内置FLASH 8GB eMMC，支持TF卡扩展，最大128G

3. **协议兼容性**：边缘计算网关支持S7等多种工业协议，满足二次供水泵房控制器的协议需求

4. **云+端解决方案**：映翰通"云"+"端"解决方案，大大缩短调试的周期，减少前端部署的工作

5. **先进传输协议**：采用MQTT物联网协议传输到云平台，比传统的VPN更有优势

6. **国际认证**：通过CE、FCC、PTCRB、CCC、Verizon Wireless、AT&T认证

7. **工业级可靠性**：全工业级设计，为现场无人值守的站点实现可靠、安全、稳定的数据传输链路

8. **丰富硬件接口**：提供丰富的硬件接口，拥有8路数字量I/O

9. **远程维护能力**：可实现对现场设备的远程控制和预防式维护

10. **二次开发支持**：配置简单易用，多种方式支持二次开发
