# 机器人远程监控解决方案

## 一、方案概述

### 1.1 项目背景

某国际知名的自动化集团公司，作为全球领先的智能自动化解决方案供应商之一，向客户提供一站式解决方案：从机器人、工作单元到全自动系统及其联网，市场领域遍及汽车、电子产品、金属和塑料、消费品、电子商务/零售和医疗保健。

当前中国构造智能制造、构造数字化机器人的热情不断高涨，社会对此项事业的重视度不断提升。在高端装备制造业发展中，智能制造是必然趋势。其中，工业机器人互联互通的应用，成为重要的智能制造的内容。推广应用机器人联网，一方面能够推动机器人智能化水平提升，另一方面改变传统的人力生产模式，同时可以对一部分脑力劳动进行替代。

在全球工业互联网浪潮日益高涨的背景下，现代工业机器人在柔性加工等生产中应用越来越广泛。生产线上的机器人、机械臂的稳定可靠性对企业生产的经济效益保证意义重大。移动工业机器人的大规模部署，工业机器人结构复杂、维护成本高对生产企业技术人员的维护能力提出高要求。要求机器人发生故障之前检测到机器人机构部、控制装置等方面的异常，并提醒用户在停机发生前进行有针对的维护维修，从而使停机时间减少为零，实现连续生产。

### 1.2 建设目标

- 通过联网进行大规模集中管理与预防性维护
- 降低人力成本和备件成本
- 解决生产压力大、维护时间短、周末检修压力巨大的运维问题
- 通过设备联网提前预警，降低事故发生可能性
- 通过设备联网收集大量数据综合分析，优化资产管理
- 实现远程诊断、预警、维护，减少停机时间

### 1.3 适用场景

- 工业机器人远程监控与维护
- 自动化生产线机器人管理
- 智能制造数字车间
- 大规模机器人自动化生产线运维
- 柔性加工生产机器人联网

## 二、需求分析

### 2.1 设备现状

- 设备类型：工业机器人、机械臂、机器人控制器
- 通信接口：LAN口、4G LTE
- 通信协议：支持多种工业协议
- 部署环境：生产车间、自动化生产线、数字车间
- 数量规模：设备量级大，大规模部署

### 2.2 核心需求

1. **集中管理需求**：机器人设备量级大，所有设备都进行预防性维护人力成本和备件成本高，需要通过联网进行大规模集中管理与预防性维护
2. **运维效率需求**：生产压力大，维护时间短，周末检修压力巨大，需要通过设备联网解决运维问题
3. **预警预测需求**：设备大停机具有不可预测性，通过设备联网提前预警，降低事故发生可能性
4. **数据管理需求**：资产管理成本高、不准确、利旧时没有可参考数据。传统的紧急性维修、修正性维修和预防性维护方式已经不能满足大规模机器人自动化生产线的运维要求，需通过设备联网收集大量数据综合分析

## 三、总体架构设计

本方案采用机器人（控制器）+ 通讯设备（工业路由器）+ 服务器 + InConnect云平台的整体架构。通过映翰通4G工业路由器IR300与现场机器人进行本地组网，4G工业路由器通过4G的方式把数据传输到云监控中心。保障数据可靠性、实时性、安全性，同时兼顾网络开销，将现场数据上传至云监控中心。工作人员在远离生产现场情况下实时地对机器人进行远程诊断、预警、维护。

映翰通InConnect云服务提供远程维护的通道，工程师通过OpenVPN客户端建立VPN隧道，对机器人突发故障快速诊断定位问题，可远程更新或修改机器人控制器程序。

### 3.1 四层架构

![拓扑图](./images/68730861.webp)

1. **感知层**：工业机器人、机械臂、机器人控制器等现场自动化设备
2. **网络层**：映翰通4G工业路由器IR300，支持4G LTE高速网络和Wi-Fi
3. **平台层**：云监控中心、InConnect云平台，提供远程维护通道
4. **应用层**：远程诊断、预警、维护、远程程序更新修改、故障快速定位

### 3.2 数据流

机器人控制器 → IR300工业路由器（4G传输）→ 云监控中心 → 远程诊断/预警/维护

远程维护通道：工程师OpenVPN客户端 → InConnect云平台 → IR300 → 机器人控制器

## 四、网络与接入方案

### 4.1 联网方式选型

采用4G LTE高速网络接入方式，支持CAT4高速网络和CAT1/CATM低速网络。凭借4G无线广域网以及Wi-Fi无线局域网等技术，提供不间断的多种网络接入能力。

### 4.2 边缘网关选型要点

**IR300工业路由器特性**：

- 支持4G LTE CAT4高速网络和LTE CAT1/CATM低速网络
- 冗余链路设计，双SIM切换，保障设备网络通信不间断
- 高可靠性设计，链路检测设计，链路层检测，检测链路情况，实现掉线自动重拨
- 保持链路长连接、PPP层检测，维持与运营商网络侧的连接，防止被强行休眠，保持网络的畅通性
- 硬件看门狗，设备故障自愈设计，设备运行故障自修复，保障设备维持高可用性
- 尺寸小巧紧凑，便于安装
- 可以稳定可靠运行，为无人值守现场提供不间断网络
- 支持LAN口，便于接入设备与调试
- 支持接入InConnect云平台，实现远程管理部署，按需建立维护通道，掌控现场
- 支持防火墙，访问控制功能，可按需设置黑白名单，允许指定IP联网
- 安全、可靠不间断的网络连接
- 高性能，体积小
- 可实现按需建立远程维护隧道，对机器人远程维护

## 五、协议与数据采集方案

### 5.1 支持协议

- **网络协议**：4G LTE CAT4/CAT1/CATM、Wi-Fi
- **安全协议**：OpenVPN、防火墙
- **访问控制**：支持黑白名单，允许指定IP联网

### 5.2 北向协议支持

- 支持接入InConnect云平台
- 支持OpenVPN客户端建立VPN隧道
- 支持远程程序更新和修改
