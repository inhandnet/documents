# 第1章 认识设备

## 1.1 概述

IR602系列是映翰通面向大规模、中速率工业物联网场景推出的轻量化5G RedCap工业路由器。产品集成5G RedCap、Wi-Fi 6和2.5G以太网，支持5G SA、链路冗余、智能链路调度、加密隧道及DeviceLive云端集中管理等功能，为跨厂区、野外及无人值守等分布式工业站点提供稳定、安全、易运维的网络连接。
产品采用工业级设计，可适应复杂工业环境，满足工业现场及分布式站点的长期稳定运行需求，为工业物联网的规模化部署提供可靠的网络基础。

需按照以下步骤将设备恢复出厂设置：

1. 设备上电，等待SYS指示灯熄灭的瞬间长按Reset按钮5-10秒，然后松开Reset按钮，此时SYS指示灯红色闪烁。

# 第2章 安装与首次使用

## 2.1 安装前准备

### 环境要求

| 项目 | 要求 |
|------|------|
| 电源 | 使用原装电源适配器 |
| 温度/湿度 | 需满足规格书要求 |
| 安装位置 | 避免强电磁干扰环境，避免与高功率设备过于接近 |
| 工具 | SIM卡、蜂窝天线、Wi-Fi天线、网线 |

> **注意**：安装完成后需确认设备是否易发生晃动，避免因设备跌落造成设备损坏。

### 准备工作

1. 安装4G/5G、Wi-Fi天线并插入SIM卡。
2. 连接电源和网线，任意LAN口连接PC。
3. 将PC的IP地址设置为与工业路由器处于同一网段。

设备LAN口默认启用DHCP Server 功能，将PC设置为"自动获取IP地址"，PC即可通过IR624获取IP地址，需确认该地址是否处于192.168.2.0网段。若PC无法通过DHCP的方式自动获取IP地址，则需手动将PC的IP地址配置为192.168.2.2~192.168.2.254中的任一地址；默认网关为192.168.2.1，子网掩码为255.255.255.0，DNS设置为8.8.8.8或从运营商获取的DNS地址。

### 网络接入方式说明

IR602支持5G/4G、有线、Wi-Fi（STA）三种网络接入方式。

#### 有线接入网络

IR602支持蜂窝、有线、Wi-Fi三种网络接入方式。设备WAN/LAN1端口支持"WAN/LAN切换"功能，该端口默认处于LAN模式，如需通过有线接入网络，需要在【Internet>上行链路列表】中手动添加WAN链路，并选择合适的联网方式（该端口支持DHCP/静态IP/PPPoE三种有线接入模式）。完成设置后，用网线将IR602的WAN口与上行设备连接即可接入网络。

#### 蜂窝接入网络

在通常情况下，按照说明完成天线安装并插入SIM卡后，IR602会自动创建拨号连接并连接到Internet。

# 第3章 常用场景配置

## 场景1：蜂窝联网

**目标**：通过4G/5G蜂窝网络接入互联网。

**前提**：已插入SIM卡并安装天线，设备已上电。

**预计用时**：约5分钟。

**操作步骤**：
1. 插入SIM卡并安装天线。
2. 设备上电，等待系统自动拨号。
3. 在通常情况下，IR602会自动创建拨号连接并连接到Internet。
4. 当需要配置APN参数时，进入【Internet】→【上行链路列表】菜单，选择Cellular，点击"编辑"按钮进入APN参数配置界面。
5. 配置APN参数（APN参数需从运营商获取）。
6. 点击"保存"并等待连接建立。

**验证方法**：
1. 检查蜂窝状态灯，确认绿色常亮。
2. 在【状态】→【链路监控】中查看蜂窝链路状态。

**常见问题**：
- 网络连接失败：检查SIM卡是否正确插入、APN参数是否正确。
- 数据发送接收异常：检查信号强度和流量余额。
- 部分专网环境下，需手动关闭【Internet】菜单下的"链路探测"功能，避免因探测不通导致蜂窝不能正常工作。

## 场景2：有线接入网络

**目标**：通过有线方式接入互联网。

**前提**：已获取上行网络参数，设备已上电且PC已连接LAN口。

**预计用时**：约5分钟。

**操作步骤**：
1. 登录设备Web管理界面。
2. 进入【Internet】→【上行链路列表】，点击"添加"按钮。
3. 选择WAN接口类型，配置联网方式（DHCP/静态IP/PPPoE）。
4. 点击"保存"。
5. 用网线将IR602的WAN口与上行设备连接。

**验证方法**：
1. 在【状态】→【链路监控】中查看WAN链路状态。
2. 通过设备自带的Ping工具测试外网连通性。

**注意事项**：
- 添加WAN接口后，原LAN1接口角色将切换成WAN。
- 删除WAN接口后，原WAN接口角色将会切换回LAN1。
- 删除WAN接口后，与WAN接口相关的静态路由、入站/出站规则、端口转发、策略路由、流量整形相关配置都将被删除。

## 场景3：接入DeviceLive云平台

**目标**：将设备接入DeviceLive云平台，实现远程管理和监控。

**前提**：设备已接入Internet，已准备好设备的序列号和MAC地址。

**预计用时**：约10分钟。

**操作步骤**：
1. 在浏览器中（建议使用谷歌浏览器），输入网址 https://device.inhandcloud.cn 进入DeviceLive登录/注册页面。单击"立即注册"以创建平台账号。

![alt text](./img/image-6.png)
<p align="center"><strong>图 3-1 DeviceLive注册</strong></p>

2. 完成账号注册后，使用用户名和密码登录到映翰通云服务平台，并选择【DeviceLive】服务。

![alt text](./img/image-7.png)
<p align="center"><strong>图 3-2 DeviceLive登录</strong></p>

3. 进入DeviceLive平台后，进入【设备】菜单，点击"添加"按钮，填写设备名称、序列号、MAC地址后点击"完成"。

![alt text](./img/image-8.png)
<p align="center"><strong>图 3-3 DeviceLive添加设备</strong></p>

**验证方法**：
1. 在DeviceLive平台【设备】列表中查看设备在线状态。
2. 点击"设备名称"查看设备详细信息。

**常见问题**：
- 设备显示离线：检查设备是否正常联网，确认序列号和MAC地址填写正确。
- IR602采用基础功能免费许可，高级功能收费许可的策略；常规的设备管理和监控功能可以免费使用，如需使用云连接等功能，需要在"企业管理>订阅>许可证"中购买高级许可证。

## 场景4：Wi-Fi接入点配置

**目标**：配置IR602作为AP提供无线网络接入。

**前提**：设备已上电，已登录Web管理界面。

**预计用时**：约5分钟。

**操作步骤**：
1. 进入【Wi-Fi】→【Wi-Fi列表】菜单。
2. 点击"添加/编辑"按钮，配置SSID名称、认证方式、密码等参数。
3. 点击"保存"。

**验证方法**：
1. 使用无线终端搜索配置的SSID。
2. 输入密码后确认可正常连接并访问网络。

**注意事项**：
- 设备默认有2.4G、5G两个主SSID，主SSID频段不支持修改且不可删除。
- 已添加的SSID频段不支持修改，信道将自动与所属主SSID的信道保持一致。
- 若用户在【Internet】菜单创建Wi-Fi(STA）接口，与Wi-Fi(STA）接口相同频段的SSID都无法启用直到Wi-Fi(STA）接口被删除。

## 4.2 Internet

可在"Internet"功能下配置每个上行接口的参数和操作模式。IR624支持有线、蜂窝、Wi-Fi三种接入网络模式。最多可以支持三个上行链路，包括 WAN、蜂窝和 Wi-Fi （STA）。WAN和Wi-Fi（STA）接口需要手动添加，并可根据需要删除；蜂窝上行链路不可删除。

### 4.2.1 有线连接

IR602支持三种有线连接方式接入网络：DHCP、静态 IP 和 PPPoE。可通过单击"编辑"按钮来修改连接方式。默认选中"DHCP"模式。

![alt text](./img/image-25.png)
<p align="center"><strong>图 4-20 有线连接配置</strong></p>

- DHCP：设备WAN接口默认开启DHCP服务，用网线将WAN接口与互联网连接，即可自动联网。
- 静态IP：可手动配置从运营商获取或与上行设备相同网段的地址，配置完成后，路由器将通过指定的静态IP接入网络。

![alt text](./img/image-26.png)
<p align="center"><strong>图 4-21 静态IP配置</strong></p>

- PPPoE：可配置宽带拨号，配置完成后，路由器将通过宽带拨号接入网络。

![alt text](./img/image-27.png)
<p align="center"><strong>图 4-22 PPPoE配置</strong></p>

- 添加WAN接口后，原LAN1接口角色将切换成WAN。
- 删除WAN接口后，原WAN接口角色将会切换回LAN1。
- 删除WAN接口后，与WAN接口相关的静态路由、入站/出站规则、端口转发、策略路由、流量整形相关配置都将被删除。

### 4.2.2 无线连接

IR602支持作为客户端接入现场AP的网络，点击【Internet】菜单中"添加"按钮，选择"Wi-Fi(STA)"，填写SSID名称和密码等参数。

![alt text](./img/image-28.png)

- Wi-Fi(STA)删除后，与Wi-Fi(STA)接口相关的静态路由、入站/出站规则、端口转发、策略路由、流量整形的配置都将被删除。

## 4.6 VPN

虚拟专用网络（VPN）是一种加密技术，用于在公共互联网上创建安全的、私人的网络连接。VPN通过加密通信数据，确保通信的机密性和安全性，防止未经授权的访问。

### 4.6.1 IPSec VPN

IPSec（Internet Protocol Security）VPN 是一种用于加强网络通信安全性的协议套件，旨在通过加密和认证来保护数据的传输。广泛应用于建立安全的远程访问、站点到站点连接以及虚拟专用网络（VPN）。

点击"VPN>IPSec VPN"下的"添加"按钮，添加新的IPSec VPN。

![alt text](./img/image-43.png)
<p align="center"><strong>图 4-37 IPSec VPN添加</strong></p>

![alt text](./img/image-44.png)
<p align="center"><strong>图 4-38 IPSec VPN配置</strong></p>

两端配置完成后，隧道即可建立。可在【状态>VPN】菜单中查看隧道建立状态。下方仅列出部分必填项的说明。

- 名称：路由器创建的IPSec VPN名称标识，主要用于本地管理。
- IKE版本：设置IKE协议使用的版本号，支持IKEv1和IKEv2。
- 预共享密钥：在IKE协商的两端设备需要配置相同的认证密钥。
- Internet接口：本地建立IPSec VPN使用的上行接口。
- 隧道模式：设置IPSec对IP报文的封装模式，支持隧道模式和传输模式。
- 对端地址：与IR624建立隧道的对端通信地址。

说明：

IR602在用IPSec VPN建立连接时，默认以使用公网地址的设备作为服务器，IPSec服务器侧的对端地址需要配置为 0.0.0.0，IPSec客户端侧的对端地址填写IPSec服务器侧的公网地址。

- 本地子网：填写需要通过IR602 IPSec VPN隧道通信的网段地址。
- 对端子网：填写隧道另一端需要通过IPSec VPN隧道通信的网段地址。
- IKE策略：支持设置IKE协议的配置。
  - 加密方式：设置IKE使用的加密算法。取值范围：DES、3DES、AES128、AES192、AES256，默认"AES128"。
  - 认证方式：设置IKE使用的认证算法。取值范围：MD5、SHA1、SHA2-256、SHA2-384、SHA2-512，默认"SHA1"。
  - DH组：设置IKE阶段密钥协商使用的DH交换参数。取值范围：1、2、5、14、15、16、19、20。
  - 超时时间：设置IKE SA存活时间，默认86400秒。
- IPSec 策略：支持设置IPSec参数配置。
  - 安全协议：设置ESP协议使用的安全协议。取值范围：DES、3DES、AES128、AES192、AES256，默认使用"AES128"。
  - 加密方式：设置ESP协议的加密算法。取值范围：MD5、SHA1、SHA2-256、SHA2-384、SHA2-512,默认"SHA1"。
  - PFS组：IPSec使用安全策略发起一个协商时，在阶段2的协商中进行一次附加的密钥交换以提高通讯的安全性参数。取值范围：1、2、5、14、15、16、19、20。
  - 超时时间：设置IPSec SA老化时间，默认86400秒。

### 4.6.2 L2TP VPN

二层隧道协议L2TP（Layer 2 Tunneling Protocol）是一种二层VPN协议，旨在提供安全的点对点或站点到站点的虚拟专用网络（VPN）连接。

**L2TP VPN客户端**

IR602可以作为L2TP客户端和位于远端的L2TP服务器建立隧道。点击"L2TP VPN>客户端"下的"添加"按钮，添加L2TP客户端。

- 名称：L2TP客户端的名称，用于本地标识。
- 状态：L2TP 客户端隧道开启/禁用开关。
- NAT：L2TP 客户端转发时的NAT功能开关。
- 上行接口：L2TP客户端与服务器进行通信的上行接口。
- 服务器地址：对端L2TP服务器的通信地址。
- 用户名/密码：两端进行L2TP协商时需要配置相同的用户名/密码。
- 认证模式：设置L2TP认证模式。

L2TP服务器一般部署于企业总部，为移动办公或分支机构提供远程访问服务。点击"VPN>L2TP VPN>服务器" 进入L2TP 服务器的编辑页面。

- 名称：L2TP 服务器名称，不支持修改。
- 状态：L2TP 服务器的功能开关，默认关闭。
- 上行接口：L2TP作为服务器时使用的上行接口。
- VPN通信地址：作为L2TP客户端的网关地址，可为L2TP客户端设备分配地址池内的地址。
- 地址池：L2TP客户端接入时用于通信的地址池。
- 用户名/密码：两端进行L2TP协商时需要配置相同的用户名/密码。
- 认证模式：设置L2TP认证模式。
- 启用隧道验证功能：启用后，两端用于隧道验证的用户名/密码需要配置相同。

## 4.7 安全

在【安全】菜单下，可根据需要设置防火墙、策略路由相关的高级功能。

### 4.7.1 防火墙

防火墙当前包括：入站规则、出站规则、端口转发、MAC地址过滤、域名过滤等功能，可根据具体的业务需求进行配置。

**入站/出站规则**

可通过"安全 > 防火墙 > 出站规则/入站规则"功能来实现基于接口的流量进出控制。例如，当受到来自特定源IP地址的大量攻击行为时，可以使用防火墙入站规则来限制来自该IP地址的流量。此外，还可通过防火墙出站规则来限制某些用户访问外部网络的权限。入站规则和出站规则在可配置的内容上相同，唯一的区别是默认规则。以下是添加入站规则的示例：

![alt text](./img/image-48.png)
<p align="center"><strong>图 4-42 防火墙入站规则</strong></p>

- 名称：设置入站规则的名称，用于本地标识。
- 状态：规则的功能开关。
- 接口：对于出站规则，指流量流出路由器的上行接口。对于入站规则，指流量进入路由器的上行接口。
- 协议：匹配流量的协议类型，支持Any、TCP、UDP、ICMP、自定义。
- 源：匹配流量的源地址，支持自定义，默认Any。
- 目的：匹配流量的目的地址，支持自定义，默认Any。
- 动作：入站规则/出站规则的对匹配流量的动作，支持允许和拒绝。
- 入站规则：外部网络访问路由器的流量管理规则，默认拒绝所有。
- 出站规则：通过路由器访问外部的流量管理规则，默认全部放行。
- 支持通过拖动"优先级"一栏的图标调整入站规则/出站规则的优先级。

**端口转发**

端口转发也被称为端口映射或端口重定向，用于将网络数据包从一个网络端口（或地址）重定向到另一个网络端口或地址。可在"安全>防火墙>端口转发"配置端口转发规则，当外部流量访问路由器的特定端口时，设备会将数据转发至内部客户端的相应端口上，实现从外部访问路由器内部的服务。

**例如：** 当需要从外部访问内部192.168.2.10客户端的1024端口服务时，将此客户端的端口映射到WAN1接口下的1024端口，外部网络只需在浏览器输入 `https://WAN1地址:1024` 即可访问目标设备数据，其中WAN1地址为WAN1接口的IP地址。

![alt text](./img/image-49.png)
<p align="center"><strong>图 4-43 端口转发配置</strong></p>

- 名称：端口转发规则的名称，用于本地标识。
- 状态：端口转发规则的功能开关。
- 接口：对内部客户端提供映射功能的上行接口，上行接口需要公网地址支持。
- 协议：端口映射流量的协议类型，支持TCP、UDP、TCP&UDP。
- 公网端口：对内部客户端提供映射功能的上行接口的端口号，需要与本地端口输入范围保持一致。
- 本地地址：外部网络需要访问的位于路由器下的目标设备地址。
- 本地端口：外部网络需要访问的目标设备的端口，需要与公网端口输入范围保持一致。

**网络地址转换**

网络地址转换是一种将IP数据包在通过路由器时重新包内源IP地址或目的IP地址的技术，可以将私网IP地址转换为合法IP地址。可在"安全>防火墙>网络地址转换"中配置源IP地址转换或目的IP地址转换规则。

![alt text](./img/image-50.png)
<p align="center"><strong>图 4-44 网络地址转换</strong></p>

- 名称：标识该地址转换规则。
- 状态：启用或停用该条规则。
- 类型：选择地址转换的类型。
  - SNAT：源IP地址转换，可将IP数据包中源IP地址字段的值转换为设定值。
  - DNAT：目的IP地址转换，可将IP数据包中目的IP地址字段的值转换为设定值。
- 协议：选择需要转换的IP数据包类型。
  - TCP：地址转换规则在TCP报文中生效。
  - UDP：地址转换规则在UDP报文中生效。
  - TCP&UDP：地址转换规则在TCP和UDP报文中生效。
- 源：数据包的源IP地址。
- 目的：数据包的目的IP地址。
- 转换后地址：根据所选择的地址转换类型，设置需要转换的值。

**MAC地址过滤**

MAC地址过滤是指禁止（或允许）MAC地址列表中的设备上网，即通过路由器上的MAC地址过滤功能控制局域网内设备的上网请求。可在"安全>防火墙>MAC地址过滤"中配置MAC地址过滤规则。

**域名过滤**

域名过滤是指禁止（或允许）客户端访问列表中设置的域名。可在"安全>防火墙>域名过滤"中配置可以访问或禁止访问哪些域名。

可在域名过滤表中添加多条规则，并允许客户端访问这些域名（白名单），或禁止客户端访问这些域名（黑名单）。

### 4.8.2 802.1X

802.1X 是一种基于端口的网络访问控制协议，用于在局域网（LAN）或无线局域网（WLAN）中对接入设备进行身份验证。通过启用 802.1X，网络能够确保只有经过认证的设备或用户才能访问网络资源，提高网络安全性。 该功能通常应用于企业、校园或分支机构网络中，可结合 RADIUS 服务器进行集中认证和管理。

![alt text](./img/image-54.png)
<p align="center"><strong>图 4-51 802.1X配置</strong></p>

- 802.1X 功能开关：用于启用或关闭 802.1X 功能。建议在需要控制网络访问的场景下保持开启，否则关闭。
 - 开启：启用 802.1X 认证功能，所有配置的认证端口将启用身份验证。
 - 关闭：关闭 802.1X 功能，端口不进行身份验证。
- 服务器：指定进行 802.1X 认证的 RADIUS 服务器IP或域名。
- 认证端口：用于启用 802.1X 身份验证的物理或逻辑端口。端口会在设备接入时触发认证请求，未通过认证的设备将被隔离。
- 计费端口：指定 802.1X 认证通过后计费或统计流量的端口。仅在启用计费功能的网络中使用。如果不涉及计费或流量统计，可留空或禁用。
- 密钥：用于 802.1X 与 RADIUS 服务器之间的安全通信。

### 4.11.8 计划重启

计划重启是一种网络设备管理的策略，允许管理员在特定时间或条件下自动重启设备，以确保设备的正常运行和性能。

可根据业务需求在"系统>计划重启"功能中设定设备定时重启的时刻，设备支持在每日、每周、每月固定时刻进行重启。

在每月重启中，当选择的重启日大于当月实际天数时，设备将在当月最后一天重启。例如，选中在每月31日重启，在只有30天的月份中会在当月30号进行重启。

### 4.11.9 日志服务器

日志服务器是一种专用服务器或软件应用程序，用于收集、存储和管理网络设备、应用程序和操作系统生成的日志信息。这些日志记录包括事件、警告、错误、活动和其他相关信息，对于监视、故障排除和性能优化非常重要。

在"系统>日志服务器"功能中启用日志文件服务器功能后，设备会定期将日志文件上传到指定的日志服务器服务器。

**Web登录管理**

当Web登录到设备本地界面超过一定时间后，将自动登出或断开连接，以保护隐私和安全。

可在"系统 > 其他设置 > Web登录管理"中设置登出时间。一旦单次登录设备Web页面的在线时间超过设定的时间，系统会自动退出登录状态，需要重新登录以继续操作。

**自动重启**

工业路由器专门设计自动重启的机制，帮助解决现场需要人工重启以恢复网络连接的情况。在"系统>其他设置>自动重启"中开启此功能后，当设备无法联网且重试一小时后仍无法接入网络时，设备将会自动重启。

**SIP ALG**
SIP ALG（Session Initiation Protocol Application Layer Gateway）是一项用于管理通过 NAT（网络地址转换）的 VoIP（基于 IP 的语音通信）呼叫的网络功能。它能够对 SIP 信令和 RTP 媒体流进行正确的地址转换和转发，从而确保 VoIP 呼叫能够在路由器环境下正常建立并保持通信连接。

# 附录 安全注意事项

1. 请使用原装电源适配器，避免因电源适配器和设备不匹配造成设备损坏。
2. 安装设备时请勿将设备安装在强电磁干扰环境下，避免与高功率设备过于接近。安装完成后请确认设备是否易发生晃动，避免因设备跌落造成设备损坏。
3. 请确认设备使用环境满足规格书所要求的温度和湿度。
4. 请定期检查设备线缆，包括网线，电源适配器连接线，保持线材清洁，如有发生破损请及时更换。
5. 清洁设备时，避免使用化学试剂直接喷洒在设备表面，避免损害外壳或内部组件。需要使用柔性的布料清洁产品。
6. 请勿私自拆修或改装设备，这将会导致安全问题并且设备会失去保修资格。
