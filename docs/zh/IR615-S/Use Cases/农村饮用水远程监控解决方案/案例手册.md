# 农村饮用水远程监控解决方案

## 一、方案概述

### 1.1 项目背景

某水处理设备企业是一家专注于高端水处理技术研发、设备生产及服务型的科技型公司。公司结合人工智能、物联网、大数据等高新技术在供水行业中应用，以智慧水务管控一体化平台建设为基础，引入超滤、纳滤系统等深度处理技术，研发制造新型高端装备与网络信息化深度融合的智能型产品，打造全新"供水中心"，将智慧化、免值守、大数据分析充分应用于市政饮用水处理、污水处理、加压泵站、城镇供水、二次供水设备、终端水质净化、农村安全饮水、分质供水等领域。

2020年，该企业率先在黔东南州200个乡镇，3000多个村庄实施农饮水监测，给老百姓提供高质量饮用水。由于各个供水站分布分散，监控和视频未进行统一管理，运行管理人员无法及时掌控所有水站的加药流程、净水流程及供水站安全情况等，存在一定的安全隐患。为此，建设高标准集中供水工程，借助信息化技术加强农村饮用水的信息化管理势在必行。

映翰通提供的IR615工业级路由器，为建设信息化管理提供稳定的传输通道，通过IPSEC VPN对数据加密传输，保障了信息的安全。映翰通DeviceManager云平台可海量接入设备，对全国各地的通信设备统一管理，实时监控流量的开销、信号状态，减少因为设备断网故障带来的损失。

### 1.2 建设目标

- 实现供水站点设备自动运行及远程监控
- 实现净水设备自动制水、自动正洗、反洗，并实时监测净水设备运行状况
- 实现供水站点集中管控，降低管理成本，提高管理水平及运行效率
- 实现水量、进水浊度、出水余氯、浊度和pH值的在线实时监测
- 实现药剂精细化投加，保证出水水质
- 实现工程重要部位安全保卫及视频监视，7×24小时不间断远程监控
- 推动水利工程标准化、信息化管理

### 1.3 适用场景

- 农村饮用水供水站点远程监控
- 市政饮用水处理
- 城镇供水、二次供水设备
- 终端水质净化、农村安全饮水
- 加压泵站监控

## 二、需求分析

### 2.1 设备现状

- 设备类型：PLC控制器、变频器、传感仪表、净水设备、水处理设备、控制器等
- 通信接口：以太网、4G LTE、LAN口
- 通信协议：IPsec VPN
- 部署环境：农村供水站点，分布分散（200个乡镇，3000多个村庄）
- 数量规模：大规模分布，需要上万级设备接入能力

### 2.2 核心需求

1. **自动化运行需求**：实现供水站点净水设备的自动化改造，自动制水、自动正洗、反洗
2. **远程监控需求**：各供水站点的运行情况实时上传至中控室，实现集中管控
3. **水质监测需求**：水量、进水浊度、出水余氯、浊度和pH值的在线实时监测
4. **智能投药需求**：通过水质及水量数据实时反馈，调节药剂投加量，实现药剂精细化投加
5. **视频安防需求**：水源地、提水泵房、清水池以及供水站等重要安保部位的7×24小时不间断远程视频监控
6. **标准化管理需求**：实现农村饮用水供水站点管理的标准化和信息化
7. **数据安全需求**：通过VPN方式加密传输数据，保障信息安全

## 三、总体架构设计

本方案采用现场自动化设备 + 通讯设备 + 监控中心 + DeviceManager云平台的整体架构。现场的水处理设备、控制器、映翰通IR615工业级路由器组成局域网。PLC控制器通过以太网的方式连接IR615，映翰通IR615路由器通过4G联网，和监控中心建立Ipsec VPN通道，把数据传输到监控中心。映翰通DeviceManager云平台可支持海量接入设备，实现集中统一管理。

### 3.1 四层架构

![拓扑图](./images/53c810ad.webp)

1. **感知层**：水处理设备、PLC控制器、变频器、传感仪表、净水设备等现场自动化设备
2. **网络层**：映翰通IR615工业级路由器，支持4G LTE网络和Wi-Fi，提供IPsec VPN加密传输
3. **平台层**：监控中心、映翰通DeviceManager云平台，支持海量设备接入和统一管理
4. **应用层**：中控室监管平台、视频监视系统、数据报表分析、远程配置维护

### 3.2 数据流

现场水处理设备/传感器 → PLC控制器 → IR615工业路由器（4G联网、IPsec VPN加密）→ 监控中心/云平台 → 中控室显示/视频监视/数据报表

## 四、网络与接入方案

### 4.1 联网方式选型

采用4G LTE无线网络接入方式，凭借3G/4G无线广域网以及Wi-Fi无线局域网等技术，提供不间断的多种网络接入能力。支持多种链路冗余备份，确保设备与监控中心之间稳定的连接。

### 4.2 边缘网关选型要点

**IR615工业级路由器特性**：

- 支持4G LTE网络，保障设备网络通信不间断
- 支持LAN口，便于设备的接入与调试
- 支持IPsec VPN，便于通过VPN方式接入监控中心，保障数据安全
- 支持网管，能够实施对离散设备的集中化管理
- 支持获取信号值、LAN口IP地址、流量开销、SIM卡号
- 全工业设计，在严苛环境下也能长时间稳定运行
- 内置软硬件看门狗，不易掉线
- 高可靠的多级链路检测与自恢复功能
- 多种链路冗余备份功能
- 支持通过API接口获取LAN IP地址、信号值、流量开销等
- 易部署、易管理：包括以太网、3G/4G和Wi-Fi在内的多种网络接入方式，可按现场条件灵活选用
- 专业易用的网络配置，逻辑清晰的WEB配置界面

## 五、协议与数据采集方案

### 5.1 支持协议

- **网络协议**：以太网、3G/4G、Wi-Fi
- **安全协议**：IPsec VPN加密传输
- **管理协议**：支持网管协议，集中化管理离散设备

### 5.2 北向协议支持

- 支持API接口获取设备状态信息（LAN IP地址、信号值、流量开销等）
- 云平台接入，实现数据上报和远程管理

## 六、方案亮点总结

1. **高可靠性连接**：IR615-S内置软硬件看门狗，不易掉线；高可靠的多级链路检测与自恢复功能、多种链路冗余备份功能，保障设备与监控中心之间稳定的连接

2. **数据安全保障**：IR615-S的安全防护涵盖IPSEC等多种VPN加密和网络安全防护措施，有效保护用户的业务数据不泄露或被窃取

3. **易部署易管理**：包括以太网、3G/4G和Wi-Fi在内的多种网络接入方式，可按现场条件灵活选用。专业易用的网络配置包括逻辑清晰的WEB配置界面

4. **DeviceManager云平台优势**：

   - 为客户提供通讯产品管理云平台
   - 实现上万级接入，统一管理
   - 实时通讯产品状态，信号值、固件版本、IP、产品型号、流量等信息
   - 实现权限分组管理
   - 实现数据报表，在线报表、流量报表等
   - 实现批量增加、删除、配置、升级等
   - 支持lan IP查看、SIM信号值查看、SIM卡号查看、流量统计、在线故障诊断分析
   - 远程故障定位和运行日志诊断，流量消耗管理，设备资产管理，设备预防性维护以及大数据挖掘等功能

5. **全工业级设计**：在严苛环境下也能长时间稳定运行，适合农村供水站点的复杂部署环境

6. **标准化信息化**：推动水利工程标准化管理，实现农村饮用水供水站点管理的标准化和信息化
