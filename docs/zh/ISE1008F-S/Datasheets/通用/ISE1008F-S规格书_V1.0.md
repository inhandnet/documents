# <span style="color: green;">1. 产品概述</span>

**ISE1008F-S 专为车载、轨道交通、工业控制及其他严酷工业环境设计。**

ISE1008F-S-8TM-24 是 8 路百兆电口的加固型工业以太网交换机，支持 8 个 10Base-T/100Base-TX M12 电口。产品符合 FCC、CE、RoHS 标准，具有 -40℃ ~ +80℃ 的宽工作温度范围，能适应复杂的电磁环境。M12 航空接头保证牢固连接，在振动和冲击等环境因素干扰下也能可靠工作，广泛应用于车载 PIS、CCTV、车载监控视频、自动化智慧工厂等场景，为用户的以太网设备连接提供可靠、高性价比的解决方案。

**产品特点：**

- **坚固设计：** 金属外壳，无风扇自然冷却，IP65 防护等级。
- **宽域适应：** 宽温（-40 ~ +80℃）、宽压（DC 12-52V）设计，M12 电源接口。
- **国际标准：** 符合 FCC、CE、RoHS 标准，EMS 各项达 Level 3，EN61000-4-8 达 Level 4。
- **智能交换：** 内带存储转发机制，支持全双工/半双工自动协商，网口全自动交叉识别（MDI/MDI-X 自适应）。
- **可靠防护：** 电源反接保护，M12 航空接头确保振动冲击环境下的可靠连接。
- **便捷部署：** 即插即用，壁挂式安装，平均无故障时间 300,000 小时。
