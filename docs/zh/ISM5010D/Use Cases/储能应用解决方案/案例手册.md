# 储能系统环网解决方案

## 一、方案概述

### 1.1 项目背景

光伏产业也称作太阳能产业，即使用太阳能级半导体电子器件吸收太阳辐射能，并使之转换成电能的产业。太阳能作为最具潜力的可再生能源，因其储量的无限性、存在的普遍性、利用的清洁性以及实用的经济性，越来越被人们所青睐。大力发展光伏产业，积极开发太阳能，在全球范围得到了空前重视，已成为各国可持续发展战略的重要组成部分。储能在整个光伏发电环节中显得尤为重要。

### 1.2 建设目标

- 实现储能系统提供稳定可靠的数据传输通道
- 支持环网冗余，保障网络可靠性

### 1.3 适用场景

- 光伏发电储能系统
- 储能电站监控
- 新能源发电场站
- 工业严酷环境下的网络通信

## 二、需求分析

### 2.1 设备现状

- 设备类型：储能系统、监控系统、工业交换机
- 通信接口：千兆RJ45网络接口、单模单纤千兆SC光口
- 通信协议：802.1Q VLAN、STP/RSTP/MSTP环网冗余协议、ITU-T G.8032
- 部署环境：电力、交通、工业等严酷工业环境
- 数量规模：多个分站房作为监控系统的子单元

### 2.2 核心需求

1. **温度适应性**：支持至少在-40～+50℃的严酷温度下正常工作
2. **光口需求**：支持2个以上单模单纤的千兆SC光口，可使用光模块接入，传输距离为20KM以上
3. **光模块需求**：光模块为宽温光模块，支持温度至少为-40～+50℃
4. **网口需求**：支持4个以上千兆RJ45网络接口
5. **网管需求**：支持WEB网管功能
6. **协议需求**：支持802.1Q VLAN、环网冗余协议等二层交换协议

## 三、总体架构设计

每个分站房作为监控系统的子单元，用环网组环方式连接，最终实现主监控室内的监控系统能够远程监视和控制管理各个点位。在系统中，采用映翰通为满足电力、交通、工业等其他严酷工业环境而设计的ISM5010D-S工业级网管型交换机，交换机之间通过现有的空余光纤+光模块以环网的方式冗余互联，同时在交换机上开启STP生成树协议保障网络的可靠性，并通过vlan划分将不同的应用进行逻辑隔离，保障应用数据安全。

### 3.1 四层架构

![拓扑图](./images/d6eb8bc3.webp)

1. **感知层**：储能系统设备、现场监控设备
2. **网络层**：ISM5010D-S工业级网管型交换机，支持环网冗余、光纤互联
3. **平台层**：主监控室监控系统
4. **应用层**：远程监视、控制管理、数据分析

### 3.2 数据流

储能设备 → ISM5010D-S交换机（环网互联）→ 主监控室 → 远程监视/控制管理

## 四、网络与接入方案

### 4.1 联网方式选型

采用工业以太网环网组网方式，交换机之间通过光纤+光模块以环网方式冗余互联，开启STP/RSTP/MSTP生成树协议保障网络可靠性。

### 4.2 边缘设备选型要点

**ISM5010D-S工业级网管型交换机特性**：

- 支持至少在-40～+50℃的严酷温度下正常工作，实际支持-40~+85℃宽温运行
- 支持2个以上单模单纤的千兆SC光口，可使用光模块接入，传输距离为20KM以上
- 光模块为宽温光模块，支持温度至少为-40～+50℃
- 支持8个RJ45千兆以太网接口，2个千兆光口，网络可扩展性高
- 支持WEB网管功能，支持console等多种管理方式
- 支持802.1Q VLAN、环网冗余协议等二层交换协议
- 支持开放的国际标准协议ITU-T G.8032，环网自愈时间<5ms
- 支持STP/RSTP/MSTP环网冗余协议，网络可靠性高
- 产品符合FCC、CE、ROHS标准
- 拥有坚固的金属外壳及防护涂层，抗压、防腐，IP40保护，防尘防污
- EMC等级达到工业4级标准，具备工业场所所需的高稳定性
- 可在5~95%（无凝霜）的严酷条件下正常工作

## 五、协议与数据采集方案

### 5.1 支持协议

- **二层交换协议**：802.1Q VLAN、STP/RSTP/MSTP
- **环网协议**：ITU-T G.8032（环网自愈时间<5ms）
- **管理协议**：WEB网管、console管理

### 5.2 北向协议支持

- 支持WEB网管协议
- 支持增强型的网络管理协议
- 支持VLAN划分进行应用逻辑隔离

## 六、方案亮点总结

1. **宽温适应性**：支持-40~+85℃宽温运行，可在5~95%（无凝霜）的严酷条件下正常工作，满足电力、交通、工业等严酷工业环境需求

2. **环网高可靠性**：支持开放的国际标准协议ITU-T G.8032，环网自愈时间<5ms。支持STP/RSTP/MSTP环网冗余协议，网络可靠性高

3. **丰富接口**：支持8个RJ45千兆以太网接口，2个千兆光口，网络可扩展性高

4. **网络安全**：支持802.1Q VLAN协议，可通过vlan划分将不同的应用进行逻辑隔离，保障应用数据安全

5. **工业级品质**：

   - 产品符合FCC、CE、ROHS标准
   - 拥有坚固的金属外壳及防护涂层，抗压、防腐，IP40保护，防尘防污
   - EMC等级达到工业4级标准，具备工业场所所需的高稳定性

6. **便捷管理**：支持增强型的网络管理协议，支持WEB、console等多种管理方式

7. **长距离传输**：支持单模单纤光模块接入，传输距离可达20KM以上
